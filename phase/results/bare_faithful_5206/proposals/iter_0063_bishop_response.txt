To optimize the `json_parser.py` for speed while maintaining correctness, we can implement a more efficient way to parse numbers by using a fixed-width buffer instead of string concatenation. This approach reduces the overhead of repeated string operations and improves performance significantly.

Specifically, we can use a fixed-size buffer to store parsed digits as they are read from the input text. Once a complete number is scanned, it can be converted directly to the appropriate data type (integer or float) without needing to repeatedly concatenate strings. This change will help in reducing the time complexity and improving the overall parsing speed of the JSON parser.
