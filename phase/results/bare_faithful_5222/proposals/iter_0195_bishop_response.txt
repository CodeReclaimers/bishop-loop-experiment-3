Consider using regular expressions for whitespace skipping instead of a per-call Python loop. This can be more efficient and concise, especially for larger inputs. The `re` module provides optimized functions for handling regex operations, such as `re.match()`, `re.search()`, and `re.finditer()`. By replacing the current `_skip_ws` function with these regular expression calls, we can reduce the runtime complexity from O(n) to O(k), where k is the number of whitespace characters.
