To make the JSON parser faster, we can optimize the whitespace skipping by using a generator expression instead of `re.match`. This allows us to process each character as needed, rather than waiting for an entire match to be completed. We also use list comprehensions where possible to avoid unnecessary allocations. Here's how you could modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    return sum(1 for _ in (c for c in text[pos:] if c not in _WS_CHARS))
```

This approach iterates over each character in `text[pos:]`, checking if it is a whitespace character. The generator expression generates an iterator of `True` values where the condition is met and `False` otherwise, which are then summed up to count the number of non-whitespace characters. This method is faster than using a regular expression because it stops scanning as soon as it finds a non-whitespace character.
