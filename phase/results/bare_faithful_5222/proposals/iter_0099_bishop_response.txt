To improve the performance of the JSON parser, we can use a technique similar to that used in regular expressions but optimized for strings in Python.
```python
# Replace the current _skip_ws function with str.lstrip
def _skip_ws(text: str, pos: int) -> int:

```

This change leverages Python's built-in string method `lstrip` to efficiently skip leading whitespace characters. This approach avoids the need for a separate loop and reduces the time complexity of the function from O(n) to O(1).
