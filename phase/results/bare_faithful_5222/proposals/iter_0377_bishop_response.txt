To optimize the `json_parser.py` for speed, we can introduce a generator function that yields each parsed value as it's encountered, rather than building the entire object in memory at once. This will allow us to process the JSON data incrementally and avoid using up all available memory.

Here's how you can implement this optimization:

```python
# Generator function to parse JSON values
def parse_generator(text: str) -> Any:
    pos = _skip_ws(text, 0)
    while pos < len(text):
        value, pos = _parse_value(text, pos)
        yield value

# Function to convert the generator into a list (optional for demonstration purposes)
def parse(text: str) -> Any:
    return list(parse_generator(text))
```

This approach improves performance by reducing memory usage and avoiding unnecessary object creation. When you iterate over `parse(text)`, the JSON parser will only process each value as it's encountered, allowing you to handle very large JSON files without running out of memory.
