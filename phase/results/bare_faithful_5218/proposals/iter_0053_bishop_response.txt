One specific change to try is to use a generator expression for the list concatenation in `_parse_object`. This avoids rebuilding the dictionary on each step, which can be costly and slow for large inputs. We can replace:
```python
out = out + [v]
```
with:
```python
out = (out + v) for v in value.values()
```
This change leverages Python's generator expressions, which are more efficient when dealing with large amounts of data.
