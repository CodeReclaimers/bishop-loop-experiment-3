One specific change to try in `json_parser.py` is to use a regular expression for whitespace skipping, which would be more efficient than iterating through each character one by one. This would involve using the `re` module in Python and replacing `_skip_ws` with something like this:

```python
import re

def _skip_ws(text: str, pos: int) -> int:
    # Use regular expression to find the first non-whitespace character
    match = re.search(r'\S', text[pos:])
    if match:
        return match.start() + pos
    else:
        return len(text)
```

This change would use a single function call to the `re` module, which is generally faster than iterating over each character.
