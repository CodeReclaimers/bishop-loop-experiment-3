To optimize the JSON parser, we can use a more efficient way to skip whitespace by utilizing Python's built-in `str.lstrip` method, which performs an O(n) operation on the string. This method is faster than manually iterating through the string and checking for whitespace characters.

```python
def _skip_ws(text: str, pos: int) -> int:
    return pos + len(text[pos:].lstrip(' \t\n\r'))
```

This change replaces the `while` loop with a call to `str.lstrip`, which is more efficient because it only checks each character once for whitespace and returns the length of the substring that has been stripped. This reduces the overall execution time of the `_skip_ws` function, leading to faster parsing performance while maintaining correctness.
