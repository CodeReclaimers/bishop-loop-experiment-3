Replace the incremental string building in _skip_ws and _skip_ws by using a single str.find call to locate the next non‑whitespace character instead of looping over each character with a Python while‑loop. This avoids the per‑character overhead of the loop and lets the C‑level string search handle whitespace skipping far faster. The rest of the parser can keep using the same _WS_CHARS set for validation, preserving correctness.
