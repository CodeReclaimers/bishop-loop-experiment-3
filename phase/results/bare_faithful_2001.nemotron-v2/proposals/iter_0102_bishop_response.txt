Replace the repeated Python while‑loops that skip whitespace (e.g., in parse, _skip_whitespace, _parse_object, _parse_array, _parse_string, _parse_value) with direct calls to str.find or str.rfind to locate the next non‑whitespace character, which eliminates the overhead of iterating through each character individually. This keeps the same logic but reduces the number of Python byte‑code steps per parse, leading to measurable speed gains.
