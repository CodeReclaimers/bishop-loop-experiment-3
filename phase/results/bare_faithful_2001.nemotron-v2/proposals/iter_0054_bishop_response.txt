Replace the per‑character whitespace skips with a single call to a compiled regex pattern `_WS_PATTERN = re.compile(r'\s*')` that consumes all whitespace at once. This eliminates the repeated Python loops and the overhead of calling `re.match` repeatedly, directly advancing `pos` to the next non‑whitespace character. The rest of the parsing logic can remain unchanged, preserving correctness while reducing execution time.
