Skip the per‑character whitespace scan in the outer loop by pre‑computing a list of all non‑whitespace character positions in the input string once and then using bisect to binary‑search the next index after the current pos; this reduces the O(n) scan to O(log n) per whitespace jump.  
Apply the same technique in _parse_object to locate the next key, colon and value delimiters, so whitespace is bypassed via fast index jumps instead of a linear search.
