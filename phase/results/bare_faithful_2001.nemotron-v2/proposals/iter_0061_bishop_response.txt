Replace the repeated `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1` loops that skip whitespace with a single call to `text.find(text[pos], pos)` (or `text.find(\'\0\', pos)` if using null byte) to jump directly to the next non‑whitespace character, which eliminates the per‑character iteration and uses a built‑in C‑level search. This change keeps the same semantics but cuts down on Python‑level loop overhead.
