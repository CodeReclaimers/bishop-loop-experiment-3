Replace the repeated `match = re.match(r'\s*', text, pos)` followed by `pos = match.end()` calls that occur at the start and end of each iteration of `_parse_object`, `_parse_array`, and `_parse_string` with a single call to a compiled `_WS_PATTERN.match(text, pos)` that directly advances `pos` to the next non‑whitespace character. This eliminates the per‑iteration overhead of creating a new match object and reduces the number of function calls.
