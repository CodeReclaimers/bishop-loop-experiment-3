Replace the repetitive per‑character whitespace loops in `parse`, `_parse_object`, `_parse_string`, and `_parse_value` with a single call to a compiled regular‑expression pattern `re.match(r'\s*', text, pos)` (or more efficiently, a single `re.sub`/`find` to skip all whitespace at once). This eliminates the O(n) Python‑level index increments and reduces the number of loop iterations dramatically, while the logic for advancing `pos` remains unchanged. By using the regex to skip all surrounding whitespace in one step, the parser processes the input with far fewer function calls and fewer Python‑level operations per character.
