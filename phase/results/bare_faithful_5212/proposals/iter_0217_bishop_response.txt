To optimize the JSON parser, we can use a more efficient way to skip whitespace. Instead of relying on Python's built-in `lstrip(' \t\n\r')`, which has a linear time complexity, we can implement our own loop that counts the number of leading spaces and tabs. This will allow us to skip whitespace at a constant rate, reducing the overhead associated with calling the built-in method.

```python
def _skip_ws(text: str, pos: int) -> int:
    n = len(text)
    count = 0
    while pos < n and text[pos] in _WS_CHARS:
        if text[pos] == " ":
            count += 1
        elif text[pos] == "\t":
            count += 4
        pos += 1
    return pos + count
```

This modification ensures that whitespace is skipped more efficiently, reducing the overall parsing time.
