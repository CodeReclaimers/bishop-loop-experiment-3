Consider replacing explicit string concatenation with `collections.deque` or similar data structures for building lists, arrays, and dictionaries to reduce overhead. This can be done by replacing:
```python
out = out + [v]
out = dict(out)
out[k] = v
```
with:
```python
out.append(v)
out.update({k: v})
```

This change avoids the need for dynamic memory allocation, string concatenation, and dictionary updates within loops.
