One specific change to consider in `json_parser.py` is to use a more efficient way to parse numbers, specifically for hexadecimal numbers (like `\uXXXX`). This can be done by creating a set of all possible Unicode characters and using it to check if a hex character represents a valid Unicode escape sequence. The current implementation checks every single character, which is slow. By preloading the set of valid Unicode characters, we can avoid checking each character individually, resulting in faster parsing times.
