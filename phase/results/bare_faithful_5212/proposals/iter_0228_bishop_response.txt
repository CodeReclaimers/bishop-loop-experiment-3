In `json_parser.py`, we can use a stack-based approach to parse JSON instead of a recursive descent parser. This will reduce overhead associated with function calls, improve memory usage, and potentially speed up parsing by avoiding unnecessary string concatenation. We can push each character onto a stack when it is encountered until we reach the corresponding closing character (e.g., `}` for objects or `]` for arrays). When a closing character is found, we pop characters from the stack and build the parsed value until the end of the nested structure is reached. This approach will allow us to process each JSON element directly without having to rebuild collections on every step.
