To optimize the JSON parser, we can use an iterative approach to build the JSON structure without rebuilding the list or dictionary on each step. This reduces the overhead of string concatenation and dictionary updates.

Here's a step-by-step explanation:

1. **Initialize an Empty Structure**: Start with an empty data structure, such as an empty list for arrays or an empty dictionary for objects.
2. **Iterate Through Characters**: Read the JSON file character by character.
3. **Handle Whitespace**: Skip whitespace characters until a non-whitespace character is encountered.
4. **Parse Values**:
   - If you encounter a `{`, start parsing an object.
   - If you encounter `[`, start parsing an array.
   - If you encounter `"`, start parsing a string.
   - If you encounter `-`, `0`, `1`, etc., parse a number.
5. **Handle Escapes**: If you encounter `\`, handle the escape sequences for special characters.
6. **Return the Result**: Once all characters are processed, return the final parsed data structure.

By using this iterative approach, we avoid the overhead of rebuilding structures on each step, resulting in faster parsing times while maintaining correctness.
