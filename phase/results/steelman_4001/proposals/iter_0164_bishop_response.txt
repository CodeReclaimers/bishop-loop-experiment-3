One specific change to try in `json_parser.py` is to use a more efficient regex pattern for number parsing. The current implementation uses a simple regex that may not always be optimized for speed, especially with larger inputs. By precompiling the regex and using its `match` method instead of repeatedly calling `re.search`, we can avoid unnecessary re-executions of the same regex on the same text. This should help reduce the parsing time significantly while maintaining correctness.
