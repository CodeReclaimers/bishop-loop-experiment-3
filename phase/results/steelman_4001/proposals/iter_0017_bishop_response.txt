The current implementation of `json_parser.py` uses a complex set of nested loops and string concatenation to parse JSON objects and arrays. This approach is correct but inefficient, especially for large inputs. A potential optimization is to use recursion instead of iteration. By breaking down the parsing process into recursive functions that handle different types of JSON values (object, array, number, string, boolean, null), we can reduce the overhead of repeated string concatenation and avoid unnecessary memory allocations. This will improve the performance of the parser while maintaining its correctness.
