To make the JSON parser faster while keeping it correct, we can use a more efficient method to skip whitespace characters. Currently, the `_skip_ws` function uses Python's built-in `while pos < n and text[pos] in _WS_CHARS:` loop which scans each character until it finds a non-whitespace one. This approach is fine for small inputs but becomes inefficient for large inputs due to its linear time complexity.

A more efficient way would be to use a regex pattern specifically designed for whitespace matching, which can be compiled once and reused for multiple passes through the text. This allows us to skip multiple whitespace characters in parallel, significantly reducing the overall parsing time.
