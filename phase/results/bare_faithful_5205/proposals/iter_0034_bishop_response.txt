To speed up the JSON parser, we can use a more efficient string concatenation strategy that avoids the overhead of `+` operator for every element in the list. We can create a list and then join it at the end instead of appending each element individually. This reduces the number of calls to `+`, which is faster than repeated concatenation.

Here's the suggestion:
- Create an empty list `out` before parsing.
- Append each parsed value to `out`.
- After parsing all values, join them into a single string using `join()` instead of repeatedly calling `+`.
