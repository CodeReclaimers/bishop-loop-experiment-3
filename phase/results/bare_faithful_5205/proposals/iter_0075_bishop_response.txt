To optimize the JSON parser, we can start by reducing the number of string concatenations used to build intermediate results. Instead of appending each value directly to a list or dictionary in `_parse_value`, we can use an in-place approach where we directly update the `out` variable based on the parsed values. This reduces the overhead of creating new strings and improves performance.

Specifically, in `_parse_object` and `_parse_array`, we can replace the following lines:

```python
out = out + [v]
out = dict(out)
```

with

```python
out.append(v)
out.update({k: v})
```

This change eliminates the need for creating temporary lists and dictionaries during parsing, resulting in a more efficient parsing process.
