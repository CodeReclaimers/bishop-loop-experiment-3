To make the JSON parser faster, we can optimize the whitespace skipping by using a generator expression instead of `lstrip()`. This allows us to skip leading whitespace on each iteration without needing to create and store intermediate strings. Here's how you could modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    return sum(1 for _ in text[pos:].lstrip())
```

This approach is efficient because it avoids creating a new string object on each iteration, which can be costly in terms of memory and performance.
