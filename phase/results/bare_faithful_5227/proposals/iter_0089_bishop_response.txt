To make the JSON parser faster, one potential change could be to use a more efficient method for parsing numbers. Instead of concatenating strings with `+=`, which is slower than using list comprehensions or the `join` method, we could modify `_parse_number` to directly convert the numeric string into its corresponding Python type (int or float) without concatenation.

This would reduce the time complexity from O(n * m), where n is the number of characters in the string and m is the length of each number being parsed, to O(n + m), which is more efficient.
