To optimize the JSON parser, we can introduce a more efficient way to handle whitespace skipping by using a generator expression within the `_skip_ws` function. This approach avoids the need for a loop in each iteration and directly yields characters that are not whitespace until a newline is encountered.

```python
def _skip_ws(text: str, pos: int) -> int:
    return next((i for i, c in enumerate(text[pos:]) if c not in _WS_CHARS), len(text))
```

This change leverages the generator expression to efficiently skip through the string without building a list of characters. The `enumerate` function is used to get both the index and character at each position, allowing us to stop processing once we encounter a non-whitespace character or reach the end of the string. This results in faster execution time while maintaining the correctness of the JSON parser.
