To improve the performance of the JSON parser, we can implement a more efficient way to skip whitespace characters by using a generator expression within a function call. This change will reduce the overhead associated with repeatedly checking each character individually. We can apply this optimization in the `_skip_ws` function as shown below:

```python
def _skip_ws(text: str, pos: int) -> int:
    # Use a generator expression to efficiently skip whitespace
    return sum(1 for _ in iter(lambda: text[pos + _] in ' \t\n\r', True))
```

This change leverages Python's iterator capabilities to iterate over the string only once, which significantly improves the performance compared to using a loop with `for` and an `if` statement. The generator expression within the `sum` function efficiently counts the number of whitespace characters without requiring additional memory for storing the intermediate results.
