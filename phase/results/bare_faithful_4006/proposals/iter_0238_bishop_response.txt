An optimized change would be to use a generator expression in the `_skip_ws` function instead of a loop for better performance. This involves replacing:
```python
def _skip_ws(text: str, pos: int) -> int:
    # Use a simple loop to skip whitespace for better performance
    while pos < len(text) and text[pos] in ' \t\n\r':
        pos += 1
```
with:
```python
def _skip_ws(text: str, pos: int) -> int:
    # Use a generator expression to skip whitespace for better performance
    return pos + sum(1 for c in text[pos:] if c in ' \t\n\r')
```
