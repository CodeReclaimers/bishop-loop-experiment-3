To optimize the JSON parser, one suggested change is to use a generator expression for whitespace skipping instead of a simple loop. This can be implemented by replacing `_skip_ws` with the following:

```python
def _skip_ws(text: str, pos: int) -> int:
    return pos + sum(1 for c in text[pos:] if c in ' \t\n\r')
```

This change leverages Python's generator expression and `sum()` function to efficiently compute the number of whitespace characters ahead without creating a new list. This is more memory efficient than the previous loop-based implementation, which constructs a separate iterator.
