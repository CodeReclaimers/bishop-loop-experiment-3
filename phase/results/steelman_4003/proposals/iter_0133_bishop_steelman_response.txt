CRITIQUE: The suggestion to use generator expressions instead of list comprehensions for parsing arrays is unworkable because it would break the expected return type contract — the parser currently returns a `list` but a generator would return a generator object. Additionally, this change would not actually avoid creating temporary lists since the parser needs to build up the final list structure regardless of whether intermediate steps use lists or generators.
