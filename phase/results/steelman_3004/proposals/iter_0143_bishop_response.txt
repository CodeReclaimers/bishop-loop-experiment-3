Replace the current while‑loop in `_skip_ws` with a single call to the compiled regular expression `_WS_PATTERN.search(text, pos)` and set `pos = match.end()` (or `len(text)` if no match), which directly jumps to the first non‑whitespace character instead of incrementing one position at a time. This eliminates the O(k) loop over each whitespace character and makes whitespace skipping O(1) per call.
