Replace the current `_skip_ws` implementation that parses whitespace using the compiled regex `_WS_PATTERN` with a simple loop that advances the index while checking membership in the pre‑computed `_WS_CHARS` frozenset. This avoids the overhead of regex compilation and searching, delivering a faster O(n) skip with no code changes to correctness.
