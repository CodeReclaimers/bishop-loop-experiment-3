Replace the linear‑scan `_skip_ws` loop in `_parse_value` with a binary search over a pre‑computed list of non‑whitespace positions so the function jumps directly to the next token instead of iterating over each whitespace character. This reduces the per‑token skipping cost from O(k) where k is the number of whitespace characters to O(log n) per skip. The list can be built once per input, keeping correctness intact.
