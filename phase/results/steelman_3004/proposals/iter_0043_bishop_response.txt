Use a precomputed lookup table that stores the index of the next non‑whitespace character for each position, then replace the linear while‑loop in `_skip_ws` with a single array lookup. Pass this `next_non_ws` list to `_parse_value` and to the parsing functions that need to skip whitespace, so each skip becomes O(1) instead of scanning characters one by one. This removes repeated character checks and eliminates the overhead of building the table repeatedly for the same input.
