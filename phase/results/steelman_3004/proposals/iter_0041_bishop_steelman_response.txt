CRITIQUE: The suggestion to precompute a lookup table for non-whitespace indices would require O(n²) space in the worst case (e.g., when input is all whitespace followed by a single non-whitespace character), making it infeasible for large inputs. It also fails to account for the fact that whitespace skipping is not a one-time operation but happens repeatedly at various positions during parsing. Additionally, the approach doesn't consider that the parser may need to skip whitespace in different contexts, and the precomputation would need to be done per string, not once per parser instance.

STEELMAN: A better approach is to compute a "next non-whitespace index" lookup table once per input string, but only for positions that are actually reached during parsing. This can be achieved by precomputing a sparse lookup table that maps each index to the next non-whitespace index, avoiding the O(n²) space issue while still providing O(1) skip time. This lookup can be built incrementally during a single pass over the string and reused for all subsequent whitespace skips.

def _build_next_non_ws_lookup(text: str) -> list[int]:
    """Build a lookup table mapping each index to the next non-whitespace index."""
    n = len(text)
    lookup = [0] * n
    # Fill from right to left
    pos = n - 1
    while pos >= 0:
        if text[pos] in _WS_CHARS:
            if pos + 1 < n:
                lookup[pos] = lookup[pos + 1]
            else:
                lookup[pos] = n
        else:
            lookup[pos] = pos
        pos -= 1
    # Adjust lookup so that each entry points to the next non-whitespace character
    for i in range(n - 2, -1, -1):
        if lookup[i] == i:
            continue
        lookup[i] = lookup[i + 1]
    return lookup

    """Skip whitespace using precomputed lookup table."""
    return next_non_ws[pos]
