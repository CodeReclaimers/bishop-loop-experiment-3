CRITIQUE: The suggestion to use binary search on a pre-computed whitespace table is flawed because it doesn't account for the fact that whitespace skipping is typically done in a streaming fashion, not in bulk. Additionally, building a cumulative table for every input would require O(n) space and time, which defeats the purpose of optimization. The approach also assumes that whitespace patterns are uniform across all inputs, which is not true for arbitrary JSON strings.
STEELMAN: A better approach would be to precompute a lookup table of the first non-whitespace character index for each position in the input string, allowing O(1) skips without requiring binary search or bulk preprocessing. This can be achieved by scanning the input once to build a table of next non-whitespace positions, then using that table during parsing.

def _build_ws_table(text: str) -> list[int]:
    """Build a table of next non-whitespace character positions."""
    n = len(text)
    ws_table = [0] * n
    pos = n
    for i in range(n - 1, -1, -1):
        if text[i] in _WS_CHARS:
            ws_table[i] = pos
        else:
            ws_table[i] = i
            pos = i
    # Adjust table so that ws_table[i] gives the index of the first non-whitespace char after i
    for i in range(n - 1, -1, -1):
        if text[i] in _WS_CHARS:
            ws_table[i] = ws_table[pos] if (pos := ws_table[i]) < n else n
        else:
            pos = i
    return ws_table
