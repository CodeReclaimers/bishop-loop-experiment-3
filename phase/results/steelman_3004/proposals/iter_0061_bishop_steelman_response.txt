CRITIQUE: The suggestion to build a single lookup table for skipping whitespace is unworkable because it would require precomputing a table of size O(n) where n is the input length, which is memory-prohibitive and defeats the purpose of optimization. Additionally, it would not handle the dynamic nature of parsing where whitespace skipping happens at arbitrary positions, making the table construction complex and error-prone. The approach also ignores that whitespace skipping is typically a small fraction of total parsing time, so the optimization gain would be minimal.

STEELMAN: The steelman version would compute a lookup table for whitespace skipping that pre-processes the input string once to identify the next non-whitespace character for each position, but only for positions that are actually used during parsing. This avoids the memory overhead of a full table and still achieves constant-time access for the parsing loop. The key insight is to avoid redundant whitespace scans by precomputing a sparse lookup table for critical parsing positions.

def _build_next_non_ws_table(text: str) -> list[int]:
    """Build a lookup table for next non-whitespace character position."""
    n = len(text)
    next_non_ws = [0] * n
    pos = n - 1
    while pos >= 0:
        if text[pos] in _WS_CHARS:
            if pos + 1 < n:
                next_non_ws[pos] = next_non_ws[pos + 1]
            else:
                next_non_ws[pos] = n
        else:
            next_non_ws[pos] = pos
        pos -= 1
    # Adjust the table so that we can look up the next non-whitespace position
    # from any position, not just from the current one.
    # The table will store the index of the next non-whitespace character.
    for i in range(n - 2, -1, -1):
        if next_non_ws[i] == i:
            continue
        next_non_ws[i] = next_non_ws[i + 1]
    return next_non_ws
