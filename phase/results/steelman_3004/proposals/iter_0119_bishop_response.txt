Replace the loop‑based `_skip_ws` function with a direct table‑based jump that advances `pos` by the pre‑computed value stored in `ws_table`. Instead of iterating character by character, look up the next non‑whitespace index in the whitespace table and set `pos` to that index in constant time. This removes the while loop entirely, so whitespace skipping is O(1) per call rather than O(k) where k is the number of whitespace characters.
