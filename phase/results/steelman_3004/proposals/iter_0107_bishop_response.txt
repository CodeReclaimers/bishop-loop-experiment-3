Pre‑compute a whitespace skip table that stores, for each position, the number of consecutive whitespace characters starting there, then replace the repeated `_skip_ws` calls with direct table look‑ups and jumps (`pos += ws_table[pos]`). This removes the per‑character loop inside `_skip_ws` and the function itself, letting the parser advance in O(1) per whitespace block. The table is built once per parse run, so the overall whitespace‑skipping cost is reduced from O(N) per call to O(1) per block.
