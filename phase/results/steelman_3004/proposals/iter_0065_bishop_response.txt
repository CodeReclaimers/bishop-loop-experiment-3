Replace the manual whitespace skipping in `_skip_ws` with a call to a pre‑computed lookup table (`_build_ws_table`) that returns the next non‑whitespace index in O(1) time, and propagate that table to `_parse_value` so all parsing steps use the table instead of repeatedly scanning characters.
