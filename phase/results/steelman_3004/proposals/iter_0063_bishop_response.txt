Replace the repeated whitespace‑skipping calls with a single precomputed lookup table that records, for each position, the index of the next non‑whitespace character. Update `_parse_value`, `_parse_object`, `_parse_array`, etc., to take this table (instead of individually calling `_skip_ws`) and let `_skip_ws` simply return the table value, eliminating the O(k) scans for each whitespace block. This reduces the skip cost to O(1) per call while preserving correctness.
