Replace the repeated character‑by‑character check in `_skip_ws` with a single jump to a pre‑computed index that marks the end of the current whitespace run, eliminating the per‑character iteration. This avoids checking each whitespace character and reduces the work from O(n) to O(k) where k is the number of whitespace runs, and it is still correct because the jump lands at the same position the loop would reach.
