Use a single pre‑computed skip table built at the start of `parse` and pass it to `_skip_ws` and all nested parsers, so whitespace jumps are done via index table look‑ups instead of repeated regex matching. This removes the overhead of compiling and evaluating `_WS_PATTERN` on every character and keeps the parsing linear. The only change is to modify `_skip_ws` to accept the table and apply it directly.
