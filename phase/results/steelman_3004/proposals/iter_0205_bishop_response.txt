Replace the linear `_skip_ws` loop with a jump‑pointer skip table that records, for each index, the farthest position where whitespace ends, allowing O(1) skips instead of iterating character‑by‑character. This table can be built once at parse start by scanning the string and storing the end of the longest consecutive whitespace run, then each skip advances directly to that position. The change eliminates the per‑character loop while preserving correctness and speeds up parsing on inputs with long whitespace sequences.
