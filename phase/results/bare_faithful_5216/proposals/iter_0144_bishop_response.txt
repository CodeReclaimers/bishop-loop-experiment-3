One potential optimization to consider is using a more efficient string concatenation method for building the parsed object. Currently, it uses repeated `out = out + [v]` or `out = dict(out); out[k] = v`, which can be slower compared to appending directly to the list. Instead, we could use a list comprehension with `append()` to build the list in one go, reducing the overhead of repeated concatenation operations.
