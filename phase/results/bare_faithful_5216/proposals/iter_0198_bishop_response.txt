To optimize the JSON parser in `json_parser.py`, we can use a more efficient way to skip whitespace by iterating through the string using a loop instead of relying on regular expressions. This approach allows us to process each character one at a time, which is generally faster than building up a match object first. Here's how it can be implemented:

```python
def _skip_ws(text: str, pos: int) -> int:
    for c in text[pos:]:
        if c not in _WS_CHARS:
            break
        pos += 1
    return pos
```

This change reduces the overhead of regular expression operations and improves the performance of the parser by reducing the number of times we need to check for whitespace.
