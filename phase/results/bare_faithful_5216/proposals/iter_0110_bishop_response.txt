To make the JSON parser faster, we can optimize the whitespace skipping by using a generator expression to find the first non-whitespace character starting from the current position in the text. This approach reduces the time complexity of finding the next non-whitespace character from O(n) to O(1). The updated `_skip_ws` function is as follows:

```python
def _skip_ws(text: str, pos: int) -> int:
    for c in text[pos:]:
        if c not in _WS_CHARS:
            return pos + c.isspace()
    return len(text)
```

This change ensures that the parser can skip past leading whitespace efficiently, reducing the overall parsing time by avoiding unnecessary calls to regex operations.
