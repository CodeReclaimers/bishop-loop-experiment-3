One possible improvement is to use `re.match` with a regex pattern instead of Python's for loop to skip whitespace. This can be more efficient than using a for loop, especially when dealing with large inputs.

```python
def _skip_ws(text: str, pos: int) -> int:
    match = re.match(r'[^\s]', text[pos:])
    if match:
        return match.start() + pos
    return len(text)
```

Explanation of the change:
1. We use `re.match` to search for a non-whitespace character starting from position `pos`. This is more efficient than iterating through each character with a for loop.
2. If a match is found, we return the start position plus `pos`, which gives us the number of characters to skip.
3. If no match is found (i.e., the input is all whitespace), we return the length of the input, indicating that there is trailing content at the end of the input.

This change makes the function faster while keeping it correct by leveraging Python's built-in regular expression support.
