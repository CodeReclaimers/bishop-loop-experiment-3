To optimize the `parse` function, we can implement a more efficient approach to skip whitespace in the input string. One way to do this is by using Python's built-in `isspace()` method which checks if a character is an ASCII white space. This method avoids the overhead of compiling regular expressions and reduces memory usage.

Here's how you can modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    while pos < len(text) and text[pos].isspace():
        pos += 1
    return pos
```

This modification eliminates the need for a regular expression match and directly checks if each character is an ASCII whitespace. By replacing `re.match(r"[ \t\n]*", text, pos)` with this simpler approach, we improve the performance of the `parse` function without compromising correctness.
