One specific change to try in `json_parser.py` is to use a regular expression to skip whitespace at the beginning of each line, instead of manually iterating through the characters and checking for space characters. This change can be made by replacing the `_skip_ws` function with the following code:

```python
import re

def _skip_ws(text: str, pos: int) -> int:
    return pos + len(re.fullmatch(r"[ \t\n\r]*", text, pos))
```

This approach leverages Python's `re.fullmatch` function, which returns a match object if the entire string matches the regular expression. This allows us to skip whitespace efficiently and accurately, reducing the number of iterations required by our parser.
