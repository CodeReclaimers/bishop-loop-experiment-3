```python
def _skip_ws(text: str, pos: int) -> int:
    m = re.match(r'\s*', text[pos:])
    if m:
        return m.end()
    return pos


def _parse_value(text: str, pos: int) -> tuple[Any, int]:
    pos = _skip_ws(text, pos)
    if pos >= len(text):
        raise JSONParseError("unexpected end of input")
    c = text[pos]
    if c == "{":
        return _parse_object(text, pos)
    if c == "[":
        return _parse_array(text, pos)
    if c == '"':
        return _parse_string(text, pos)
```

In this implementation, we create an empty list `out` and append each parsed value to it. After parsing the entire string, we convert the list to a dictionary using `dict(out)`. This approach reduces the number of allocations and improves memory usage compared to concatenating strings in each step.
