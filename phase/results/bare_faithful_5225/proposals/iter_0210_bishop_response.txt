To speed up the JSON parser, we can optimize the whitespace skipping by using a generator expression within `_skip_ws` instead of `lstrip`. This allows us to process characters one by one without loading the entire string into memory.

```python
def _skip_ws(text: str, pos: int) -> int:

```

This change reduces the need for a separate loop and indexing operation, resulting in faster execution time.
