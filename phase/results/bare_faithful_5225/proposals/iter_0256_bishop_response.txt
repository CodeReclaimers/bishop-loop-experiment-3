To speed up the JSON parser, we can implement a more efficient way to parse numbers by using a dedicated function that scans characters until it finds a valid number format. This function will avoid calling `ord()` for each character, which is expensive and reduces the overhead of Python's built-in string methods.

Based on these counts, we can reconstruct the number as a floating-point or integer value directly without converting to an intermediate string representation. This method will be faster for numbers with more significant digits compared to the current approach, which scans each character individually.

The implementation of this change involves creating a new function `_parse_number` that takes the text and position as arguments, processes the characters until it forms a valid number, and then returns the parsed number along with the updated position. This function will be called from `_parse_value` after skipping whitespace and checking for other value types like strings or booleans.
