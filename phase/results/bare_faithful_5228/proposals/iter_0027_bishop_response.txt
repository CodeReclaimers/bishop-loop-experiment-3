To make the JSON parser faster, we can optimize the `_parse_string` function by using a more efficient string concatenation approach. Specifically, instead of building the string incrementally with `out = out + "\f"` or `out += "\n"`, we can use `"".join(chars)` to concatenate multiple characters at once, which is generally faster.
