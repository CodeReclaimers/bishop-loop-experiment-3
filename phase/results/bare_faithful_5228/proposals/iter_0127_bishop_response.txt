One possible optimization is to use an iterator instead of a list to build the object or array, which reduces memory allocation and improves performance. You can achieve this by replacing `out = out + [v]` with `out.append(v)` in `_parse_object` and `_parse_array`, and replacing `out = dict(out); out[k] = v` with `out[k] = v` if the key is not already present in the dictionary.
