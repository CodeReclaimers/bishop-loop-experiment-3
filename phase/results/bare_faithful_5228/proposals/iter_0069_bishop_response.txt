To optimize the `json_parser.py` for faster parsing, we can use a more efficient way to parse numbers. Instead of scanning character-by-character with explicit predicates, we can use a regular expression to match the number format directly. This approach will reduce the time complexity from O(n) to O(1), where n is the length of the input string.

We will replace the existing code in `json_parser.py` that checks for digit characters and signs with a single call to a regular expression. This will significantly speed up the parsing process, especially for large JSON strings.
