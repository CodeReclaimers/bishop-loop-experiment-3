To make the JSON parser faster, we can optimize string concatenation by using a preallocated buffer instead of repeatedly appending to the same string. This reduces the overhead of string resizing and copying. We also need to ensure that our approach correctly handles surrogate pairs in Unicode strings. Here's how you can implement this change:

2. **Copy Characters Safely**: When appending characters to the buffer, use `buffer.write` instead of string concatenation (`+`). The `write` method is more efficient than string concatenation because it does not involve creating new strings or resizing existing ones.

3. **Correctly Handle Surrogate Pairs**: Ensure that when parsing Unicode strings, we handle surrogate pairs correctly to avoid incorrect decoding. This can be done by using the `unichr` function with the appropriate range for high and low surrogates.
