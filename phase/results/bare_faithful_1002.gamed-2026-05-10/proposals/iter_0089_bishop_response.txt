To optimize the `json_parser.py` for speed while keeping correctness, we can precompile regular expressions using the `re` module before parsing the input. This avoids the overhead of regex matching on every character, which can significantly improve performance especially for large JSON documents.

The changes involve replacing the direct loop with a precompiled regex match in the `_skip_ws` and `_parse_value` functions. This change will make the parser faster by reducing the number of regex operations performed during parsing.
