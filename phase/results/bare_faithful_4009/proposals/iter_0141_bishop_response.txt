To optimize the JSON parser in `json_parser.py`, one potential change is to use a more efficient string concatenation method within the `_parse_value` function. The current implementation appends each part of the value to a string using the `+=` operator, which can be slow for large strings. Instead, consider using the `extend()` method to add elements to a list and then convert it back to a string at the end. This reduces the overhead of string concatenation and improves performance.
