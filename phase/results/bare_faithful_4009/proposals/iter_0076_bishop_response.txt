To optimize the `json_parser.py` for faster performance, we can modify the `_parse_string` function to handle escape sequences more efficiently by using a dictionary to map escape characters to their corresponding characters. This will reduce the time complexity of checking if an escape sequence is valid. Here's how you can do it:

```python
# Dictionary mapping escape sequences to their corresponding characters
ESCAPE_CHARACTERS = {
    '"': '"',
    "\\": "\\",
    "/": "/",
    "b": "\b",
    "f": "\f",
    "n": "\n",
    "r": "\r",
    "t": "\t"
}

def _parse_string(text: str, pos: int) -> tuple[str, int]:
    if text[pos] != '"':
        raise JSONParseError(f"expected string at {pos}")
    pos += 1
    out = ""
    while pos < len(text):
        c = text[pos]
        if c == "\"":
            return out, pos + 1
        elif c in ESCAPE_CHARACTERS:
            out += ESCAPE_CHARACTERS[c]
            pos += 1
        else:
            raise JSONParseError(f"unexpected escape sequence at {pos}")
        pos += 1
    raise JSONParseError("unterminated string")
```

This change improves the performance of parsing strings by avoiding multiple iterations to check if an escape character is valid. The dictionary lookup in `ESCAPE_CHARACTERS` ensures that we can directly map and append the corresponding characters, reducing the time complexity from O(n) to O(1).
