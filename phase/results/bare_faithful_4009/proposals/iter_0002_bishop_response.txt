One specific change to try is to use a more efficient way to skip whitespace in `parse()`. Instead of using a Python loop, we can leverage the `str.strip()` method, which already handles all the whitespace characters efficiently.

The updated code would look like this:

```python
def _skip_ws(text: str, pos: int) -> int:
    return text[pos:].strip().find(" ")
```

This change makes it faster by avoiding the overhead of manually iterating through the string and skipping characters.
