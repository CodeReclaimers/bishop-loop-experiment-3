One specific change to try in `json_parser.py` is to implement a more efficient algorithm for handling escaped characters in strings. This can be achieved by using a state machine or a lookup table to map escape sequences to their corresponding characters. The current implementation of `_parse_string` uses a while loop with explicit checks for each character, which can be slow and inefficient. Using a precomputed mapping would allow us to quickly look up the corresponding characters without having to perform multiple comparisons. This would reduce the number of iterations needed and improve the overall performance of the parser.
