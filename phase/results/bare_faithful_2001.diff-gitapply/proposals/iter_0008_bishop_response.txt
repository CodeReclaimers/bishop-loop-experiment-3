Replace the manual per‑call loops that skip whitespace (`_skip_ws`) and scan digits/float parts (`_parse_number`) with regular‑expression calls that match the entire whitespace run and numeric literal at once. Using a single regex match eliminates the repeated Python‑level `while` iterations, turning what is O(n) in Python loop overhead into a C‑level regex engine operation, which is dramatically faster while still yielding the same character positions.
