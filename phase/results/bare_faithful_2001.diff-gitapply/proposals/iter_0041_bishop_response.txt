Replace the per‑call character‑by‑character whitespace skipping in both `parse` and `_skip_ws` with a single compiled regular‑expression call that removes all whitespace characters from the input string up front, so the parser works on a clean string and no longer advances the index to skip whitespace. This eliminates the inner while loop that checks each character against the set `_WS_CHARS`, dramatically reducing overhead while still correctly handling the positions for error reporting.
