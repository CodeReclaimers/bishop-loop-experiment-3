To optimize the current implementation, we can use a technique known as "lazy parsing" where we only parse parts of the JSON data when needed. This approach reduces the amount of time spent parsing and improves the overall performance of the parser. One potential change is to add a `parse_partial` function that takes in a portion of the text to be parsed and returns a `ParsedJSON` object containing the parsed data. The `ParsedJSON` object can then be used for further processing without fully parsing the entire JSON document.
