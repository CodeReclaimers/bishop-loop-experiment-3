Replace the frequent calls to _skip_ws with a lightweight manual loop that advances the position index while the character at the current index is a whitespace, and update the _skip_ws function to do the same work but without using a regular‑expression match each time. This removes the overhead of re‑compiling and traversing a regex at every whitespace‑skipping step, which is the dominant cost in the parser. The change keeps correctness because the loop still skips any consecutive whitespace characters before a token.
