```python
def _skip_ws(text: str, pos: int) -> int:
    whitespace = iter(' \t\n\r')
    return sum(1 for _ in range(pos + len(text[pos:].lstrip(whitespace))))
```

This approach uses a generator expression to iterate over each space character found after the current position. The `sum` function then counts the number of spaces, which is faster than repeatedly calling `str.lstrip(' \t\n\r')`.
