To improve performance, we can use a more efficient method for handling whitespace skipping by utilizing Python's built-in `str.lstrip()`. This function removes leading whitespace from the string in constant time, which is faster than manually iterating over each character and checking if it is a whitespace.

Here’s how you can modify the `_skip_ws` function:

```python
# Replace the existing _skip_ws function with this:
def _skip_ws(text: str, pos: int) -> int:
    return pos + len(text[pos:].lstrip(' \t\n\r'))
```

This change will reduce the time complexity of skipping whitespace from O(n^2) to O(n), where n is the length of the string.
