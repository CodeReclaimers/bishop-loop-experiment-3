To optimize the `json_parser.py` for parsing JSON, we can use a technique called "lazy parsing" to avoid building the entire list of values in one go. This approach reduces memory usage and potentially speeds up the parsing process by processing each character as it comes in.

Here's how you could implement lazy parsing:

1. Instead of building a list of all values at once, we can use an iterator that yields individual parsed values as they are found.
2. When encountering an object or array, we start parsing it lazily and yield the results as they are added to the current value being built.

This way, each parsed value is only added when it's needed, which reduces memory usage and speeds up the parsing process.
