To improve the speed of the JSON parser, we can optimize the number parsing by avoiding redundant checks for digit characters after the negative sign. This can be achieved by introducing a `pos` variable to track the position in the string and checking each character only once.

**Solution:**
- Keep track of the current position `pos` in the string.
- When reading a number, start from the character after the minus sign (`pos += 1`) if it's negative.
- For digits, check each character only once as long as it's within the range of valid digit characters (`_DIGIT_CHARS`). This avoids redundant checks and improves parsing speed.
