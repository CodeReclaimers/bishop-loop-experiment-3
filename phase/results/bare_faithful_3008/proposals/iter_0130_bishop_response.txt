Replace the per‑token calls to _skip_ws with a single sequential while‑loop that skips all leading whitespace at once, e.g., in _parse_value and _parse_object instead of invoking _skip_ws before each check. This removes redundant function calls and lets Python advance the index in a tight loop, which the interpreter executes faster than multiple separate checks. The loop still uses the built‑in text[pos] in _WS_CHARS set, preserving correctness while cutting the overhead of repeated _skip_ws calls.
