Replace the tight‑loop whitespace scan in _skip_ws (and the repeated while‑loops in _parse_value, _parse_object, and the sub‑loops that check whitespace) with a single text.find call that jumps directly to the next non‑whitespace character. By using a non‑loop, index‑jumping method, the parser eliminates repeated character‑by‑character checks, reducing CPU cycles while still yielding the same position. This change improves speed without altering the logic that determines where each token ends.
