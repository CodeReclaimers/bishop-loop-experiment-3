Replace the current `_skip_ws` implementation with a single `text.find(''.join(_WS_CHARS), pos)` call that returns the next non‑whitespace index, since `str.find` is implemented in C and avoids the Python‑level loop. This eliminates the per‑character iteration over `_WS_CHARS` and makes whitespace skipping O(1) instead of O(k) where k is the number of consecutive whitespace characters. Because the parser only needs to locate the next token, the correctness is preserved as long as the trailing‑content check remains unchanged.
