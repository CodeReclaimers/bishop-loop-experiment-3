Replace the `_skip_ws` loop with a single `text.find` call that returns the index of the first non‑whitespace character, removing the need to check each character against `_WS_CHARS` and the character‑by‑character `while` loop. This single‑operation lookup is O(k) but avoids the overhead of iterating manually and doing set membership tests, which is the source of the reject‑based speed loss. The rest of the parser can keep using the new index as before.
