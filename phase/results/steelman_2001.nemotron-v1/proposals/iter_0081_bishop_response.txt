In `_parse_string` replace the repeated `out = out + c` and `out = out + escaped_char` constructions with a list buffer that collects all characters, then return `''.join(buf)` at the end of the function. This eliminates the O(n²) cost of string concatenation while preserving correctness, because all characters are joined once in linear time. The rest of the parser, including array building, already uses in‑place updates, so no further changes are needed.
