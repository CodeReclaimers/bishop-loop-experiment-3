In `_parse_string`, collect characters and the results of escaped sequences into a list instead of repeatedly concatenating with `out = out + c`, then replace the final loop that builds the string with `return ''.join(buf)`. This eliminates O(n²) string‑concatenation overhead and, because it is done once, reduces allocation time. The same pattern can be applied to the escape‑sequence handling within the same function to avoid intermediate string rebuilds.
