Replace the repeated string concatenations in `_parse_string` by buffering characters in a list and joining the list into a single string at the end of the function, instead of using `out = out + c` in a loop. This eliminates the O(n²) cost of building the string incrementally while preserving all escape‑sequence handling logic. The change is applied only in `_parse_string`, where the existing escape‑sequence processing can continue to accumulate characters in the same list buffer and produce the final string with `''.join`.
