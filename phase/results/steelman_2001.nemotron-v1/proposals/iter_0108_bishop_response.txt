Replace the repeated string concatenations in ``_parse_string`` and the escape‑sequence handling loop with a character buffer (a Python list). Instead of building the result with ``out = out + c`` each iteration, append the character (or the full escape sequence) to the list with ``buffer.append(ch)``, and after the loop construct the final string once with ``''.join(buffer)``. This eliminates the O(n²) cost of creating many intermediate string objects and reduces the number of memory allocations.
