In the `_parse_string` function replace the repeated `out = out + c` calls with a list `chars = []` that appends each character (including decoded escape values) and then construct the final string with `out = ''.join(chars)` after the loop. This eliminates O(n²) string concatenation cost while preserving exact output. The same pattern can later be applied to the array‑building step (though it already uses `append`).
