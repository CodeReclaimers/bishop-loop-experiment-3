In _`_parse_string`, replace the repeated `out = out + c` string concatenations with an in‑place accumulation in a list that is joined only once at the end of the function. This eliminates the quadratic cost of building a new string on each character and reduces the number of allocations to a single join. By buffering characters in the list and joining once, the string builder becomes linear‑time while preserving the exact escape‑sequence semantics.
