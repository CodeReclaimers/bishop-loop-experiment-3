Replace the repeated string concatenation `out = out + c` (and similar for escape sequences) in the `_parse_string` loop with an in‑memory list that stores each character, then build the final string once via `''.join(list)` at the end of parsing; this avoids the O(n²) cost of repeated string creation while keeping correctness. The only other place where strings are built is in the Unicode escape handling, where those can also be accumulated in a list before joining.
