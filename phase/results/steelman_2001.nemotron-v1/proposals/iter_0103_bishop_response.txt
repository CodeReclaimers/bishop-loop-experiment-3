Replace the line‑by‑line string concatenation in `_parse_string` with a list‑based builder: instead of `out = out + c` accumulate each character (or escaped sequence) into a `chars` list with `chars.append(c)` and only invoke `''.join(chars)` once at the end of the function. This removes the O(n²) cost of repeated string creation while preserving exact escape handling. The rest of the parser already uses `out[key] = value` for objects and `out.append` for arrays, so this single change further avoids unnecessary rebuilds.
