Replace the string‑concatenation pattern `out = out + c` (used in `_parse_string` and the escape‑sequence handling) with a list‑based buffer: instead of building a new string on each character, append the character to a list with `out.append(c)` and, when the string is complete, join it once with `''.join(out)`. This eliminates the quadratic cost of repeated string concatenation and makes the parsing linear.
