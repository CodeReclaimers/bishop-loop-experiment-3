Replace the repeated `out = out + c` construction in `_parse_string` with a list accumulator that collects each character (including processed escape sequences) and builds the final string only once via `''.join(list)`. This eliminates the O(n²) cost of many string concatenations while preserving correctness. The change should be applied to the loop that writes to `out` within `_parse_string`, and any escaped character output should also append to the list rather than creating temporary strings.
