Replace the repeated string concatenation inside `_parse_string` with a list accumulation: instead of updating `out = out + c` on each iteration, append each character to a list and join the list once at the end. This eliminates the O(n²) cost of repeated string building while preserving the exact sequence of characters, including escaped control characters and Unicode escapes. The change only affects the string‑building logic in `_parse_string` and does not modify the object‑building code, which is already optimal.
