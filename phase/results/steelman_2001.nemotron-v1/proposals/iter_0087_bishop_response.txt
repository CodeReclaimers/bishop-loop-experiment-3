In `_parse_string`, stop updating the output string with `out = out + c` or `out = out + escaped_char`. Instead, push each character (including any escaped characters) onto a list buffer `out.append(char)` and, once the string is finished, replace it with `out = ''.join(out)` or assign the joined result back. This eliminates the O(n²) cost of repeated string concatenation while preserving correctness.
