To optimize the JSON parser, we can use a regex to scan numbers instead of character-by-character scanning. This will reduce the time complexity from O(n) to O(log n), where n is the length of the number string. We can replace `_parse_number` with the following function:

```python
import re

def _parse_number(text: str, pos: int) -> tuple[float | int, int]:
    match = re.match(r"[-+]?\d+(\.\d+)?([eE][-+]?\d+)?", text[pos:])
    if not match:
        raise JSONParseError(f"bad number at {pos}")
    value = float(match.group(0))
    return value, pos + len(match.group(0))
```

This function uses a regular expression to match the different possible forms of numbers (integer, floating-point, scientific notation) and returns the parsed value along with the new position in the text. This approach is faster than character-by-character scanning but still maintains the correctness of the JSON parser.
