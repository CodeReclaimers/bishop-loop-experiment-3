To improve the speed of the JSON parser, we can optimize the logic for handling numbers. Currently, the parser scans each character as a separate token, which is unnecessary. Instead, we can use a regular expression to match numbers efficiently.

Specifically, we can define a `NUMBER_RE` regex pattern that matches the different types of numbers (integer, floating-point) and use it to find the end of each number in one pass through the input string. This will reduce the number of substring operations and improve the overall performance of the parser.
