To optimize the JSON parser, we can avoid unnecessary string concatenation by using a list to store parsed values. This reduces the overhead of repeatedly constructing strings on each level of recursion. Here's how you could implement this optimization:

```python
def parse(text: str) -> Any:
    if not isinstance(text, str):
        raise JSONParseError("input must be a string")
    pos = _skip_ws(text, 0)
    if pos >= len(text):
        raise JSONParseError("empty input")
    value_list: list[Any] = []
    pos = _parse_value(text, pos, value_list)
    if len(value_list) != 1:
        raise JSONParseError("expected exactly one top-level value")
    return value_list[0]


def _skip_ws(text: str, pos: int) -> int:
    n = len(text)
    while pos < n and text[pos] in _WS_CHARS:
        pos += 1
    return pos


def _parse_value(text: str, pos: int, value_list: list[Any]) -> int:
    pos = _skip_ws(text, pos)
    if pos >= len(text):
        raise JSONParseError("unexpected end of input")
    c = text[pos]
    if c == "{":
        return _parse_object(text, pos, value_list)
    if c == "[":
        return _parse_array(text, pos, value_list)
    if c == '"':
        return _parse_string(text, pos, value_list)
```

This optimization works as follows:

- The `value_list` is used to accumulate parsed values. Instead of creating a new list each time `_parse_value` is called, we append values directly to this list.
- This change reduces the overhead of string concatenation by avoiding unnecessary calls to the `+` operator, which can be costly in terms of performance.
- The `value_list` is then returned as the final parsed result.
