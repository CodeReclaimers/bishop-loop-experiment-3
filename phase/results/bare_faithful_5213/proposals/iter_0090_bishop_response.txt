One potential optimization idea is to use a regular expression for whitespace skipping instead of a per-call Python loop, as regex operations are generally more efficient than simple string manipulations. This change can be implemented by replacing `_skip_ws` with the following:

```python
import re

_WS_CHARS = re.compile(r"[ \t\n\r]")
```

This implementation uses a compiled regular expression to match whitespace characters and directly uses the `match` method to find them, which is much faster than iterating through the string manually.
