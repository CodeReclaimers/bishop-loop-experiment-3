**Optimization:** Use a more efficient method to skip whitespace characters in the `_skip_ws` function. Instead of iterating through each character and checking if it's whitespace, use a regular expression that matches whitespace efficiently.

**Explanation:** Using `text[pos:].lstrip(' \t\n\r')` is not optimal because it involves creating a new string and iterating over its characters again. A more efficient approach would be to use the `re.match` function from the `re` module, which can match patterns without consuming characters from the input.

**Efficiency Improvement:**
```python
import re

def _skip_ws(text: str, pos: int) -> int:
    # Use regular expression to find and remove leading whitespace
    return re.match(r'^\s+', text[pos:].lstrip(' \t\n\r')).end()
```

This change uses `re.match` to scan the input string from the given position for a sequence of one or more whitespace characters, then returns the end position of this match. This method is faster because it avoids unnecessary string operations and leverages Python's built-in regular expression support for efficiency.
