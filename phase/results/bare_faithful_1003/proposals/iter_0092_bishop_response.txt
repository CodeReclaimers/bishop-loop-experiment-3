To improve performance, we can use a stack-based approach for parsing objects and arrays, rather than using recursion. This allows us to avoid deep recursive calls, which can lead to a stack overflow with large JSON inputs. The `stack` variable keeps track of the current state of the parser, and we push tuples onto the stack to indicate the type of structure (object or array) and any associated data. When we encounter a closing brace or bracket, we pop the top tuple from the stack and continue parsing the remaining content within that structure. This approach reduces the overhead of function calls and recursion, resulting in faster execution times.
