To optimize the `parse` function, we can implement a technique called "lookahead" or "stateful parsing". This approach allows us to predict the next character in the string and use that information to decide how to proceed with parsing.

In this modified version of the parser, we would keep track of the current state of the parsing process. Depending on what character we see next, we can adjust our parsing logic accordingly. For example, if we see a digit, we know that it's part of a number, and we can parse it immediately without waiting for the rest of the string to be available.

This approach would allow us to skip over unnecessary whitespace and improve parsing speed while keeping the correctness of the output intact.
