To speed up the JSON parser, we can optimize the `_skip_ws` function by using a generator expression that yields whitespace characters in one pass through the string. This reduces the number of character-by-character comparisons needed to skip spaces. The modified function would look like this:

```python
def _skip_ws(text: str) -> int:
    return next((pos for pos, c in enumerate(text) if not c.isspace()), len(text))
```

This approach avoids creating a list of whitespace characters and instead yields them one by one as they are found, which significantly improves the performance for large input strings.
