To improve performance, we can use a more efficient way to skip whitespace in `json_parser.py`. Instead of checking each character for whitespace, we can use a regular expression to match whitespace characters at once using the `re` module. This will significantly speed up the parsing process by reducing the number of function calls and checks.

```python
import re

def _skip_ws(text: str, pos: int) -> int:
    # Use re.match() to skip whitespace - much faster than character-by-character
    while re.match(r'\s+', text[pos:]):
        pos = pos + len(re.match(r'\s+', text[pos:]).group())
    return pos
```
