To optimize the `json_parser.py` file for faster performance while maintaining correctness, we can introduce a more efficient way to skip whitespace. One approach is to use regular expressions instead of character-by-character checks in the `_skip_ws` function. Regular expressions are generally faster and more concise than character-by-character loops.

Here's how this change would look:

```python
import re

def _skip_ws(text: str, pos: int) -> int:
    # Use regex to skip whitespace - much faster than character-by-character
    match = re.match(r'\s*', text[pos:])
    if match:
        return pos + len(match.group(0))
    return pos
```

This change leverages Python's built-in `re` module, which provides powerful regular expression capabilities. By using `re.match`, we can efficiently find and skip any whitespace characters in the input string. This not only speeds up the parsing process but also makes the code more readable and maintainable.
