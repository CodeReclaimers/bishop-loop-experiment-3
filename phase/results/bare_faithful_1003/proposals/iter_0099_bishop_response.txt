To improve the speed of the JSON parser, a potential change could be to use a more efficient way to skip whitespace characters. One approach is to use the `str.isspace()` method which returns `True` for all whitespace characters and `False` otherwise. This method is implemented in C and can be much faster than manually iterating through each character of the string. The `skip_ws` function could then be modified as follows:

```python
def _skip_ws(text: str, pos: int) -> int:
    # Use isspace() to skip whitespace - much faster than character-by-character
    while pos < len(text) and text[pos].isspace():
        pos = pos + 1
    return pos
```
