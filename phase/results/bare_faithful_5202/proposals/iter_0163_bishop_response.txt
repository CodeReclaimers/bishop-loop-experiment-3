To speed up the JSON parser, we can leverage Python's built-in string methods for checking if a character is whitespace or not. This avoids the need to manually compare each character against a fixed set of whitespace characters.

Here’s how you might modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    try:
        # Use the built-in lstrip method to remove leading whitespace
        return len(text[pos:].lstrip(' \t\n\r'))
    except IndexError:
        return pos
```

This approach is efficient because `lstrip` operates in O(n), where n is the length of the string, compared to manually iterating through each character. This change should significantly improve performance without compromising correctness.
