Replace the iterative `_skip_ws` loop with a single call to the pre‑compiled `_WS_RE` that finds the end of the current whitespace run: `pos = _WS_RE.search(text, pos).end()`. This skips all consecutive whitespace characters in one operation, greatly reducing loop overhead, while the regex matches exactly the same set of JSON whitespace (`space, tab, newline, carriage return`). The rest of the parser can remain unchanged.
