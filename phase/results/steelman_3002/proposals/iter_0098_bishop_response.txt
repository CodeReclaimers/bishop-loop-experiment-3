Replace the current `_skip_ws` implementation that uses the compiled regex `_WS_RE.search` with a simple manual loop that increments the index while comparing each character directly to the whitespace set `' \t\n\r'`. This avoids the overhead of a regular‑expression match for each whitespace skip and makes the function O(k) in the length of the skipped segment without the regex compilation cost. This change is both correct and significantly faster.
