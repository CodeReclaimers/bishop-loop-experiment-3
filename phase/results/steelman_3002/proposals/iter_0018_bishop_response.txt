Convert the input string to a `bytearray` at the start of `parse` and replace all `text[pos]` calls with `text[pos]` on the bytearray; this eliminates Python‑level string indexing and allocation overhead, speeding up character look‑ups while preserving exact same logic. After the conversion, the parser will read each character via direct byte reads, which is faster than repeatedly creating temporary string slices. This change keeps the parser’s correctness intact because it only changes the underlying representation of the character stream.
