Replace the character‑by‑character checks in `_parse_bool` and `_parse_null` with a single `str.find` lookup that moves the position directly to the end of the token (e.g., `pos = text.find("true", pos)` or `pos = text.find("null", pos)`). This eliminates the need to iterate through each character of the literal, dramatically reducing work per token while preserving correctness.
