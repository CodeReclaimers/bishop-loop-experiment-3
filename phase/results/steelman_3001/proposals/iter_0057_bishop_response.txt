Replace the per‑call whitespace‑skipping loop in _skip_ws with a single call to text.find to locate the next non‑whitespace character, so the function returns the index in O(1) time instead of scanning each whitespace character individually. This eliminates the O(k) cost per skip where k is the number of consecutive spaces, keeping the overall parse correct because it still returns the exact end position of the whitespace run. The public parse function and all error checks remain unchanged.
