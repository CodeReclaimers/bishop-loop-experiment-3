Replace the per‑character while loop in `_skip_ws` with a single call to `text.find(next(c for c in text[pos:] if c not in _WS_CHARS), pos)` (as used in the earlier implementation) so whitespace is skipped by the C‑level `find` function instead of a Python loop.
