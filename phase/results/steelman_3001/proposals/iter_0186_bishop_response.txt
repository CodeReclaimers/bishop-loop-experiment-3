Replace the line `out = dict(out); out[k] = v` inside `_parse_object` with a direct assignment `out[k] = v`, so the dictionary is not rebuilt on every iteration. Likewise, remove the extra `out.append("\f")` and use an immediate `out.append(c)` when appending characters, avoiding the creation of a new list at each step. These changes prevent repeated object creation and simplify the inner loop, which is the main source of the slowdown.
