Replace the `_skip_ws` implementation with a call to a pre‑compiled regular‑expression `_WS_PATTERN.match(text, pos)` instead of scanning characters with a Python loop or `text.find`. The regex’s `match` returns the end position of the longest whitespace span in C code, which is far faster than the per‑character Python loop. This eliminates the O(n) Python‑level whitespace skip each time the parser traverses input, while preserving the same correct behavior.
