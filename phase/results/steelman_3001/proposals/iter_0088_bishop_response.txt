Replace the Python‑level while loop in _skip_ws that iterates over _WS_CHARS with a single C‑level call to str.find to locate the next non‑whitespace character, which removes the per‑character Python overhead and reduces the per‑call cost to O(1). Because str.find returns the same index as the current pos plus the number of skipped characters, the parser’s logic remains unchanged. This single conversion makes the whitespace‑skipping step much faster while preserving correctness.
