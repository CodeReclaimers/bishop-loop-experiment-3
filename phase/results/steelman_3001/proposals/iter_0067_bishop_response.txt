Replace the per‑call `_skip_ws` loop that manually walks through whitespace by using `text.find` (or `str.index`) to locate the next non‑whitespace character or the end of the string in a single O(1) operation. This eliminates the Python loop for whitespace skipping, which is the dominant cost in both `_skip_ws` and `_parse_value` calls. The change keeps the same logic while drastically reducing the number of character checks performed.
