To optimize the `parse` function, we can use a stack-based approach to handle nested objects and arrays more efficiently. This will reduce the overhead of recursive calls and improve performance by avoiding unnecessary string concatenations. The idea is to keep a stack of states, where each state represents a part of the JSON object or array being parsed. When we encounter an opening brace `{` or `[`, we push a new state onto the stack; when we encounter a closing brace `}` or `]`, we pop a state from the stack and continue parsing the content within that state. This approach ensures that we can parse nested structures without having to repeatedly call the same functions at every level, which is the main bottleneck in the current implementation.
