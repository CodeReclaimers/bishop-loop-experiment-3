You can implement a more efficient way to skip whitespace by using Python's `str.find` method instead of a loop, which is generally faster for finding specific characters in strings. Here’s how you can modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    # Find the first non-whitespace character and return its index
    return text.find(None, pos)
```

This approach leverages Python's built-in string method `find`, which returns the lowest index in the string where the specified value (or substring) is found. If the value is not found, it returns `-1`. This makes the `_skip_ws` function more concise and efficient by avoiding a manual loop and directly finding the next non-whitespace character.
