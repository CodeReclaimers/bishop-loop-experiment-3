To speed up the JSON parser, we can use a more efficient string concatenation method that is tailored for parsing purposes. Specifically, instead of using `out = out + "\f"` or `out = out + "\n"`, which involve creating new strings each time, we can utilize the `join` method on a mutable list to concatenate the characters directly into the final result without needing to build new strings at each step.

This approach reduces overhead and improves performance by avoiding the overhead of string creation. The mechanism is as follows:
1. Initialize an empty list `out_list` to store the concatenated characters.
2. Iterate through the input text character-by-character.
3. For each character, add it to `out_list`.
4. After processing all characters, join the elements of `out_list` into a single string and return it.

This change reduces the number of string allocations and concatenations, resulting in faster parsing times.
