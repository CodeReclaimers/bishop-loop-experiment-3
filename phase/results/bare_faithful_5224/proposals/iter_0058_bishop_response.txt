To speed up the JSON parser, we can consider a more efficient way to handle whitespace skipping. One approach is to use a generator expression within the `skip_ws` function to filter out whitespace characters directly without converting the entire string to a list of characters for each iteration. This reduces the overhead of string slicing and concatenation.

Here's how you could implement this change:

```python
def _skip_ws(text: str, pos: int) -> int:
    return next((i for i in range(pos, len(text)) if text[i] not in _WS_CHARS), len(text))
```

This modification improves the time complexity from O(n) to O(1) per iteration by skipping whitespace characters directly.
