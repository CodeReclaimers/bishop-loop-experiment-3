One specific change to try in `json_parser.py` is to switch from using a list (`out = out + [v]`, `out = dict(out); out[k] = v`) for object/array building to using string concatenation and rebuilding-on-each-step collection (`out += "\t"` or `out += " "`), which avoids the overhead of creating new lists in each iteration. This change aims to reduce the number of allocations and improve performance significantly, while still maintaining correctness.
