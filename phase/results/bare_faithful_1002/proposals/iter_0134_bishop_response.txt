To optimize the JSON parser, we can use a technique called "stateful parsing" instead of an iterative approach. This involves keeping track of the current state of parsing and transitioning between states based on the characters encountered in the input string.

In our `parse` function, we can define a list of states that correspond to different parts of the JSON structure (object, array, number, string, boolean, null). We can use a dictionary to map each state to its corresponding parser function. When we encounter a character, we transition to the appropriate state and update the current value accordingly.

For example, when parsing an object or array, we can keep track of the current key or index that we are building up. When we encounter a colon (`:`), we can move to the next state and continue parsing the value for the key-value pair. Similarly, when parsing a number, we can build up the number as we encounter digits and other characters.

By using this stateful approach, we can avoid the overhead of repeatedly parsing the same parts of the input string multiple times, which can significantly improve the performance of the parser.
