A possible optimization idea is to preprocess the input string by removing whitespace characters at the beginning of each line before parsing. This can significantly reduce the number of calls to `_skip_ws`, which currently involves a regex search, and could improve performance for inputs with many consecutive whitespace characters.

To implement this improvement, you could add a new function called `strip_lines` that takes a string as input and returns a new string with all leading whitespace characters removed from each line. This function can be used before parsing the input text in `parse`.
