Replace the current `_skip_ws` implementation that scans character by character with a direct call to `text.find_first_not_of_whitespace(pos)` (or `str.find`) which returns the index of the next non‑whitespace character in a single O(1) operation. This eliminates the loop that repeatedly checks `isspace`, which was the main source of overhead. The rest of the parser remains unchanged, preserving correctness while dramatically reducing runtime.
