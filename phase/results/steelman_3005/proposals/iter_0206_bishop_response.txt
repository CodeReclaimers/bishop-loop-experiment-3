Replace the regex‑based `_skip_ws` implementation with a simple while‑loop that directly checks and advances the position using `while pos < len(text) and text[pos].isspace(): pos += 1; return pos`. This removes the overhead of searching the compiled pattern and makes whitespace skipping O(k) where k is the number of whitespace characters rather than scanning the regex engine. The rest of the parser already uses the new position correctly, so correctness is preserved.
