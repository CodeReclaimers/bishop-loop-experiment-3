Replace the manual character‑by‑character loop in `_skip_ws` with a single call to the pre‑compiled regex `_WS_RE.match(text, pos).end()` (or to `len(text)` if no match), which returns the next non‑whitespace index in one step instead of iterating over each whitespace character. This eliminates the per‑character loop, reduces overhead, and keeps the same safety checks.
