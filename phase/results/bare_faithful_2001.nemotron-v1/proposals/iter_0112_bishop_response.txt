Replace the repeated while‑loops that skip whitespace (e.g., `while pos < len(text): if text[pos] not in ' \t\n\r': …`) with calls to `pos = text.find('\S', pos)`, which jumps directly to the next non‑space character. This eliminates the per‑character checks and regex‑based whitespace handling, allowing the parser to locate tokens in constant‑time strides and thus speed up the main parsing loop.
