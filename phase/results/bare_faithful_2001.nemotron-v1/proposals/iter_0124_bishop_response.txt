Replace the repeated `text.find('\S', pos)`/whitespace‑skipping loops around the input with a single pre‑processing step that collapses all whitespace using a compiled regex, e.g. `text = re.sub(r'\s+', '', text)`. This eliminates the overhead of scanning the string multiple times while still handling all valid JSON whitespace, and can be applied once at the top of `parse` and `_parse_object`, so the subsequent position arithmetic runs on a compact string.
