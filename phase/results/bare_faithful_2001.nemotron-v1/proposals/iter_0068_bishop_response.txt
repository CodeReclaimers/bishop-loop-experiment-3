Replace the global `_WS_RE` regex and the `_skip_ws` implementation that relies on it with a direct `str.find` scan that returns the next non‑whitespace index in a single C‑level call. This eliminates the overhead of compiling and executing a regex for every whitespace block. Since whitespace skipping is already handled manually with `str.find`, removing any regex‑based code around it will make the parser faster without affecting correctness.
