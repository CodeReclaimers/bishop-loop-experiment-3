Replace the repeated `pos = text.find('\S', pos)` loops in `parse` and `_parse_*` functions with a single regex call that extracts all non‑whitespace ranges and advances `pos` to the start of the next range, so the parser skips whitespace only once per token instead of calling `find` repeatedly. This reduces the overhead of multiple `find` calls and eliminates the loop‑control overhead, making the code faster while preserving correctness.
