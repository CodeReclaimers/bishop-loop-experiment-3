Replace the repeated `while pos < len(text): if text[pos] not in ' \t\n\r': pos += 1` loops that skip whitespace in `_parse_value` and `_parse_object` with a single call to `_WS_RE.search(text, pos)` and set `pos = match.end()`. This removes the incremental loop overhead and lets the compiled regex handle all whitespace in one pass, which the benchmark shows is faster while preserving correctness.
