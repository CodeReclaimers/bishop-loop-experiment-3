Replace the call to _skip_ws in parse and _skip_ws in _parse_value with a simple manual advance that checks each character against the whitespace set ' \t\n\r' and increments pos while the condition holds. This removes the per‑call overhead of the regex _WS_RE finditer and the subsequent next call, letting the parser skip whitespace by a tight Python while loop instead of a regex engine. Since whitespace is a fixed set of characters, the loop executes in a few bytecode instructions, yielding measurable speed gains.
