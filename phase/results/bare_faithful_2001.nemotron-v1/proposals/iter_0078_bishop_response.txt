Replace the `_skip_ws` function with a simple while‑loop that advances `pos` past each whitespace character (`' \t\n\r'`) one at a time, instead of using the regular‑expression‑based regex search. This removes the overhead of compiling and calling `re.finditer` for every call and makes whitespace skipping linear O(k) instead of O(n) per call. The rest of the parser already works with the resulting `pos`, so correctness is preserved.
