To speed up the JSON parser, we can precompute a set for character classes such as whitespace and digit characters to improve membership checks. This reduces the time complexity of checking if a character belongs to a specific class from O(n) to O(1). The current implementation already includes these sets in `_WS_CHARS` and `_DIGIT_CHARS`. We can also optimize the loop that skips whitespace by using regular expressions for longer runs, which is faster than a loop over each character.
