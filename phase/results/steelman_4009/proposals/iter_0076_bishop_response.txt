To optimize the `json_parser.py` for faster performance, we can make a few changes to reduce redundant whitespace handling at every level of recursion. One approach is to use a single global variable to track the current position in the input text and only increment it when a character that doesn't cause a change in the parsed output is encountered. This avoids unnecessary string concatenation and rebuilds-on-each-step collection (`out = out + [v]`, `out = dict(out); out[k] = v`).
