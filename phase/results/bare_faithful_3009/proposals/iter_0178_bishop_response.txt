Replace the whitespace‑skipping helpers `_WS_PATTERN` and `_skip_ws` with inline checks against the precomputed `_WS_CHARS` set, using a simple `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1` loop instead of invoking the compiled regex each time. This eliminates the overhead of regex compilation and avoids the function call, making the fast path for whitespace handling O(1) per character. The change keeps correctness because the same character membership test is used.
