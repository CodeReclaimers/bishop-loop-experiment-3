Remove the compiled regular‑expression `_WS_PATTERN = re.compile(r'[ \t\n\r]*)` and the only function `_skip_ws` that currently uses it, replacing it with the existing manual loop that checks `_WS_CHARS` directly. This eliminates the regex compilation cost and allows the parser to skip whitespace in pure Python, which is faster for short inputs. The correctness remains unchanged because the loop already performs the same character‑by‑character whitespace skipping.
