Replace the use of the compiled regular‑expression _WS_PATTERN in the whitespace‑skipping calls inside _parse_object and _parse_string with a call to the simple _skip_ws function, which walks the string with a while loop instead of invoking regex matching. This eliminates the overhead of regex compilation and matching, using only constant‑time character set lookups that are faster for short whitespace runs. The change maintains correctness because _skip_ws behaves exactly like the regex’s effect on the allowed whitespace characters.
