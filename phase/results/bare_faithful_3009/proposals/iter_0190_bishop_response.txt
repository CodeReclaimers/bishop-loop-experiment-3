Replace the calls to the compiled regex `_WS_PATTERN.match` inside `_parse_object` and `_parse_value` with a direct call to the `_skip_ws(pos)` function, updating `pos` to its return value instead of using regex match results. This eliminates the overhead of the regular‑expression engine for trivial whitespace skips, which are O(1) operations when using the pre‑computed `_WS_CHARS` set. The change keeps the same behavior while removing the regex‑based latency.
