Replace all occurrences of the `re.compile(r'[ \t\n\r]*').match(...).end()` pattern with the existing `_skip_ws` function that advances `pos` in O(1) time. By removing the regex overhead and using the pre‑computed character set directly, the parser will iterate character‑by‑character only when needed, cutting the cost of the regex matching.
