Replace the usage of the compiled regular‑expression _WS_PATTERN.match in parse and _parse_object with the simpler _skip_ws function, which manually advances pos by looping over _WS_CHARS instead of invoking a regex each time. Since _skip_ws is already O(1) per character and has no regex compilation cost, this eliminates the overhead of repeated regex matching while preserving the same whitespace‑skipping behavior.
