Replace the _skip_ws function that currently uses a compiled regex to detect whitespace with the equivalent while‑loop that iterates character‑by‑character and checks membership in the _WS_CHARS frozenset. This eliminates the per‑call regex compilation and matching overhead, relying only on fast set lookups, which makes the function faster while preserving exact behavior. The change targets the whitespace‑skipping step, the most latency‑sensitive part of the parser.
