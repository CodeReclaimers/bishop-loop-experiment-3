Replace the use of the compiled regex _WS_PATTERN in the _skip_ws and parse functions with a direct lookup in the frozenset _WS_CHARS, advancing pos by a simple while loop instead of invoking match each time. This eliminates the overhead of regex matching and string search while preserving the exact same whitespace‑skipping behavior. Consequently, the parser will be faster because the only operation per character is a constant‑time set membership check.
