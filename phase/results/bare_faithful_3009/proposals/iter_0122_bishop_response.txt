Build a one‑pass pre‑computed “whitespace jump” array that, for each index, stores the position right after the longest whitespace run starting there. Replace all manual while‑loops that manually advance `pos` by indexing this array, so whitespace skipping becomes a single array lookup instead of repeated character checks. This eliminates the overhead of the regex match and string iteration for each segment, turning the cost from O(n) per call to O(1) per segment.
