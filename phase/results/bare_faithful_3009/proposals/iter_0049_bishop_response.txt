Replace the whitespace‑skipping logic with a direct while‑loop that advances the index while the character is in the pre‑computed `_WS_CHARS` set, eliminating the overhead of compiling and invoking the regex pattern. This removes the `re` call inside `_skip_ws`, turning each skip into a simple O(1) membership test and pointer increment. The rest of the parser can keep using the standard `_skip_ws` function, which already does this with a loop, so the change is purely the removal of the regex implementation.
