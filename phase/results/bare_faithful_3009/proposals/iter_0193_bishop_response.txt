Replace all calls to the compiled regular‑expression `_WS_PATTERN` for skipping whitespace with the dedicated `_skip_ws` function, which performs a simple linear scan without regex overhead. This change eliminates the per‑iteration cost of matching and directly advances the index, keeping the same correctness while speeding up the parser. The function is already defined and used elsewhere, so the switch can be made uniformly across the whitespace‑skipping sections.
