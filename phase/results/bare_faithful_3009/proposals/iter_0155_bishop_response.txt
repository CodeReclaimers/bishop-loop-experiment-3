Replace the `_skip_ws` function with a simple `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1` loop inside each place it is called (e.g., at the start of `_parse_value`, `_parse_object`, and `_parse_array`). This avoids the overhead of matching a compiled regex on every call and directly uses the precomputed `_WS_CHARS` set for O(1) character checks. Since the logic is already in the outer `parse` loop that also skips whitespace, this change removes an unnecessary function call while keeping the same correctness.
