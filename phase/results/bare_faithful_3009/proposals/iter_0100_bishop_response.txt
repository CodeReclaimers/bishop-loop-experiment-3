Replace the _skip_ws function, which currently uses a compiled regex to find whitespace, with a simple loop that advances the position while the current character is in the pre‑computed _WS_CHARS set; this avoids the overhead of regex matching for each whitespace segment. Since _WS_CHARS is a constant frozenset, membership tests are O(1) and the loop will be significantly faster than repeatedly invoking a regex, while preserving the same whitespace‑skipping behavior.
