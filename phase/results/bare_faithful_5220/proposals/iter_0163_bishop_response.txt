To optimize this Python JSON parser, consider the following change:

### Suggestion

**Description**: Modify the `_parse_string` function to read the string character by character, directly appending each character to a `str` object, rather than using `out = out + v`. This approach avoids the overhead of string concatenation and reassignment for every character, making it faster.

### Explanation

- **Character-by-Character Parsing**: Directly building the string is more efficient because:
  - It reduces the number of function calls.
  - It avoids the overhead of modifying a list in-place, which can be costly in terms of performance.
  - It minimizes the need for resizing and reassignment of strings.

By changing `_parse_string` to read the input character by character using a `str` object, you eliminate the time-consuming operations involved with string concatenation and updates. This change significantly improves the parsing speed while maintaining the correctness of the JSON parser.
