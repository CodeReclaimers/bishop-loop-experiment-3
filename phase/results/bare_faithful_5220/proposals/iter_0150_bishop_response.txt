To optimize the JSON parser, we can use a technique called "lazy parsing" where we only parse the necessary parts of the input as we encounter them. This approach reduces the number of unnecessary operations and improves performance.

In the `_parse_value` function, we can avoid creating new lists or dictionaries for each value by directly updating existing ones. For example, instead of adding a new element to `out`, we can directly assign its value to an existing key in the dictionary.

This optimization makes it faster by reducing the number of operations and improves memory usage. It also avoids unnecessary overhead when parsing large JSON documents.
