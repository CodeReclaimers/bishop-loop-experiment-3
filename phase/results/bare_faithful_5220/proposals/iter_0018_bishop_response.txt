Optimize the `parse` function by using a stack-based approach to build the JSON object or array, reducing the need for string concatenation and rebuilding at each step. This can be achieved by maintaining a stack of values that are being built as you parse the input text. When you encounter a closing brace or bracket, you can pop the values from the stack to complete the object or array. This approach reduces the overhead of string concatenation and allows the parser to avoid rebuilding the JSON structure after each key-value pair or element is parsed.
