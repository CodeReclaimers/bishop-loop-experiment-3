To make the JSON parser faster while keeping it correct, consider using a generator expression instead of concatenating strings to build dictionaries and lists. This approach eliminates the overhead of string concatenation and reduces the number of calls to `out = out + [v]` or `out = dict(out); out[k] = v`, which are more expensive operations than direct dictionary updates. Additionally, optimize the `_parse_number` function to handle large numbers efficiently by avoiding unnecessary divisions and checks for trailing zeros.
