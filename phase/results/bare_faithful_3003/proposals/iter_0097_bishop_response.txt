Replace the per‑character whitespace loop in `_skip_ws` with a single `text.find(' \t\n\r ', pos)` call that returns the index of the next non‑whitespace character (or the string length if none remain). This skips all whitespace at once instead of incrementing the index one character at a time. Because `find` operates in C, it is far faster than the Python loop while still yielding the same result.
