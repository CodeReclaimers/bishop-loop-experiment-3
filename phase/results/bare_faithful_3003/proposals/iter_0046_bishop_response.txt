Replace the per-call `_skip_ws` that walks the string character‑by‑character with a single `str.find` call that jumps directly to the next whitespace character, for example:

```python
def _skip_ws(text: str, pos: int) -> int:

```

This eliminates the Python loop entirely, letting the C‑level `find` method handle whitespace skipping at a speed‑up.
