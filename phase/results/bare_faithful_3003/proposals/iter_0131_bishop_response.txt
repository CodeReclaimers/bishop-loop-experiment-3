Replace the repeated string‑concatenation used to build objects (`out = out + [v]`) and arrays (`out = dict(out); out[k] = v`) with a single pass that uses `list.append` / `dict.append` and then constructs the final container once, so the parser avoids allocating new strings on every iteration.
