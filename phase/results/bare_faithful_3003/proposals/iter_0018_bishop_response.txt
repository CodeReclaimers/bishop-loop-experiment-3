Replace the per‑character whitespace‑skipping loop in `_skip_ws` (the while‑loop that increments `pos`) with a single call to `text.find_first_of(_WS_CHARS, pos)`, which returns the next non‑whitespace character index directly, eliminating the O(k) loop and thus cutting the cost of every whitespace‑skip operation. This change keeps the same correctness since `find_first_of` does exactly what the loop does, but it is a single‑pass, constant‑time operation instead of repeated Python bytecode executions.
