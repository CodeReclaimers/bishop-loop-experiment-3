In the recursive descent functions that build objects and arrays, replace the string‑concatenation or collection‑rebuilding steps (such as `out = out + [v]` and `out = dict(out); out[k] = v`) with `out.append(v)` and `out[k] = v` (or use `dict.update(k, v)`) so each iteration creates only the final structure instead of allocating a new string or dict each time. This eliminates the costly per‑step allocations while preserving the same logical flow.
