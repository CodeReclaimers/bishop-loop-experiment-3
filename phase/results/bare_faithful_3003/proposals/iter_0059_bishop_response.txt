Replace the repeated string concatenation used to build object keys, array elements and string literals with a list that accumulates the fragments and joins them once at the end, as the list‑append and `''.join` approach is O(n) versus the O(n²) cost of concatenating strings each step. This change applies to `_parse_object`, `_parse_array` and `_parse_string`’s output‑building logic while leaving the core parsing logic unchanged.
