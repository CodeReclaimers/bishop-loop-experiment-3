Replace the iterative whitespace‑skipping loop in `_skip_ws` with a single `text.find(' \t\n\r', pos)` call that returns the index of the next non‑whitespace character (or `len(text)` if none remains). This eliminates the per‑character loop and makes whitespace probing O(1) per call. Because all downstream parsers already start at a non‑whitespace index, the same `pos` value can be reused, preserving correctness while dramatically reducing CPU time.
