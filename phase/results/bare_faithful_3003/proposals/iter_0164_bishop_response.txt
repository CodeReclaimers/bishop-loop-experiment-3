Replace the per‑call Python loop in `_skip_ws` with a binary‑search lookup on a pre‑computed list of all non‑whitespace character positions in the input string; this eliminates the O(n) scan each time whitespace is skipped. The list can be built once at the start of `parse`, and the function then returns the index or the end of the string in O(log n) time using `bisect`. This reduces the constant factor of the inner loop while preserving correctness.
