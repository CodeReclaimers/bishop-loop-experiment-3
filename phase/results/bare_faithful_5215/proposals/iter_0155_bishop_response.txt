To speed up the JSON parser, we can optimize the string scanning to be done using a single loop that reads one character at a time until the end of the string is reached. This approach reduces the overhead of repeatedly calling `isinstance` and other checks for each character.

```python
def _parse_value(text: str, pos: int) -> tuple[Any, int]:
    # Read one character at a time until we reach the end of the string
    while pos < len(text):
        c = text[pos]
        if c in _WS_CHARS:
            pos += 1
            continue
        if c == "{":
            return _parse_object(text, pos)
        if c == "[":
            return _parse_array(text, pos)
        if c == '"':
            return _parse_string(text, pos)
```

This change avoids the overhead of repeatedly calling `isinstance` for each character and directly checks if the character is whitespace or one of the JSON literal characters. This reduces the time complexity from O(n) to O(1), where n is the length of the string.
