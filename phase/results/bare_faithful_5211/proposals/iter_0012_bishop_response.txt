To speed up the JSON parser, we can use a more compact representation for numbers by directly parsing integers and floating-point numbers without converting them to strings. This will reduce the number of unnecessary string conversions and improve performance. We can achieve this by modifying the `_parse_number` function in `json_parser.py`. Specifically, we can check if the current character is a digit or a dot before scanning further digits to determine whether it's an integer or a floating-point number. If it's an integer, we continue parsing until we encounter a non-digit character. Similarly, if it's a dot, we parse until we encounter a non-digit or a 'e'/'E'. This approach will significantly reduce the time complexity of parsing numbers from the JSON input.
