   - If the character is a boolean (`"true"` or `"false"`), parse it and update the current context accordingly.

   - If the character is a number, parse it and append its value to the current context's collection.
3. When parsing is complete, pop the stack until it's empty.

This approach avoids building the entire output structure in memory at once, reducing the time complexity from O(n) to O(log n), where n is the length of the input text. The use of a stack ensures that we can handle nested structures efficiently without having to reconstruct them every time.
