2. **Character-by-Character Parsing**: Iterate through the string character by character:
   - If the current character is a digit, update the decimal pointer to this position.
   - If the current character is a period (`.`), set `decimal_ptr` to the current position and continue scanning for digits after it.
3. **Parsing Numbers**: Once we have identified the start and end of the number, use these positions to parse the number as needed.
