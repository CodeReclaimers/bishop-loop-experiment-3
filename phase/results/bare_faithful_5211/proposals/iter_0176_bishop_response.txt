One optimization idea is to use a more efficient way to scan numbers in `json_parser.py`. Instead of scanning character-by-character, we can use regular expressions to look for valid number patterns and then convert them to the appropriate data type. This can be done by using `re.match()` to find a match for a specific pattern that represents a number and then parsing it accordingly. This approach can reduce the time complexity from O(n) to O(1), where n is the length of the input string.
