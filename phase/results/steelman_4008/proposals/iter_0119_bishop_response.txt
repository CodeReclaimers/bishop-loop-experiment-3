To speed up the JSON parser, you can optimize the whitespace skipping by using `str.find()` to locate the first non-whitespace character efficiently. This change will reduce the number of comparisons and improve performance. The updated `_skip_ws` function is shown below:

```python
def _skip_ws(text: str, pos: int) -> int:
    # Use str.find() to efficiently skip whitespace
    try:
        return pos + text[pos:].index(next(c for c in text[pos:] if c not in ' \t\n\r'))
    except ValueError:
        return len(text)
```

This change leverages the `next()` function combined with a generator expression to find the first non-whitespace character, which is then used to determine the position of the next non-whitespace character. This approach avoids using direct character scanning and reduces the number of comparisons required, resulting in improved performance.
