CRITIQUE: The suggestion to use generator functions for parsing objects and arrays is unworkable because it would break the expected API contract where `parse()` returns a complete parsed value, not a lazy iterator. This approach would also complicate the recursive descent parsing logic and make it impossible to validate the full structure before yielding results. Additionally, it wouldn't actually reduce memory usage significantly since the parsed data still needs to be stored in memory to be returned.

STEELMAN: The steelman is to implement a streaming parser that processes objects and arrays incrementally without building intermediate lists/dicts in memory, while still maintaining the same public API. This can be achieved by using a state machine that builds the final structure incrementally through a single pass, avoiding the need for intermediate collections that are rebuilt on each step.
