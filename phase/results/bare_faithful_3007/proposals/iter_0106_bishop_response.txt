Replace the manual while‑loop in `_skip_ws` with a single call to the pre‑compiled `_WS_RE.span(text, pos)[1]` to jump over all whitespace in one step. This eliminates the per‑character loop and O(1) set lookups, letting the compiled regex handle the work efficiently while still skipping only valid whitespace.
