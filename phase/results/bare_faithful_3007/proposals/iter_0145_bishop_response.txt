Replace the current `_skip_ws` implementation that uses the compiled regex `_WS_RE.span` with the existing manual loop that checks `_WS_CHARS` membership, removing the regex call entirely. This switches from invoking the regex engine for each whitespace skip to a simple O(1) set lookup, which avoids the overhead of regex matching while preserving the same correctness. The change is confined to the `_skip_ws` function and its calls throughout the parser.
