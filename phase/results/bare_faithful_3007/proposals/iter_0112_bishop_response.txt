Replace the current `_skip_ws` implementation, which loops character‑by‑character using a set lookup, with a single call to the pre‑compiled regex `_WS_RE.span` to obtain the end index of the next whitespace run in one operation. This eliminates the O(k) loop for each whitespace sequence (where k is the length of the run) and makes whitespace skipping O(1) per call, while preserving correctness because `_WS_RE` matches the same whitespace characters defined in `_WS_CHARS`.
