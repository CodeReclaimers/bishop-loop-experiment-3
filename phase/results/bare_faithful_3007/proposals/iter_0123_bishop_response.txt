Replace the _skip_ws function’s current implementation that calls _WS_RE.span with a simple while‑loop that checks each character against the pre‑computed set _WS_CHARS, advancing the index while the current character is in that set. This avoids the regex engine’s overhead and makes white‑space skipping O(k) where k is the number of whitespace characters, which is asymptotically faster than the regex‑based approach.
