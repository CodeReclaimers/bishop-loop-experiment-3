Replace the manual loop in _skip_ws that checks each character against _WS_CHARS with a single call to the compiled regex _WS_RE match at the current position; let pos be _WS_RE.match(text[pos:]).end to jump to the next non‑whitespace character in O(1) time. This eliminates the per‑character membership checks while maintaining the same O(1) lookup semantics for whitespace.
