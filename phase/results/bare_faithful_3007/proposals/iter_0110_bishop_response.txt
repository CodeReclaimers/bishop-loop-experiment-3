Replace the _skip_ws function so it iterates manually over the input string, advancing the index while the current character is in the pre‑computed _WS_CHARS set, instead of calling _WS_RE.span which performs a full regex search each time. This eliminates the overhead of regex compilation and avoids scanning beyond the necessary whitespace, making the loop O(1) per character check. The change is limited to _skip_ws and its usage in parse, and it retains correctness because it checks the same character set.
