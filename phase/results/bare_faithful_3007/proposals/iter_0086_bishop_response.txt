Replace the per‑character loop in `_skip_ws` that checks `text[pos] in _WS_CHARS` with a single call to the compiled regex `_WS_RE.span(text, pos)[1]`. This leverages the regex engine’s optimized C‑level scan, returning the index past any whitespace in one operation instead of iterating character by character. The change keeps correctness because the same set of whitespace characters is still consumed, but the function now runs faster.
