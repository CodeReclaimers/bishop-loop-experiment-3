To improve the performance of the JSON parser in `json_parser.py`, we can optimize the string building by directly using list and join operations instead of repeatedly concatenating strings. This reduces the overhead of creating intermediate strings, which can be particularly slow for large inputs.

Here's a brief explanation of the change:
- We use a list to store each character as it is parsed.
- After parsing each value (including strings), we append the list of characters to the result list.
- Finally, instead of joining the list with `join()`, we concatenate the list directly using the `+` operator. This avoids creating an intermediate string for each concatenation operation.

This change makes the parser more efficient by avoiding unnecessary string creation and reduces the overall time complexity from O(n^2) to O(n), where n is the length of the input JSON text.
