To optimize the JSON parser in `json_parser.py`, consider the following change:

#### Change Suggestion:
Use a deque for efficient string building instead of list concatenation, which is more memory-efficient and faster.

#### Explanation:
Using a deque for string building allows us to add characters to the end and remove them from the front in constant time (`O(1)`), rather than having to concatenate strings with the `+=` operator, which has linear time complexity (`O(n)`). This change significantly reduces the overhead associated with string concatenation in large JSON documents.
