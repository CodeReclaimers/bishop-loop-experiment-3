```python
def _skip_ws(text: str, pos: int) -> int:
    # Fast whitespace skipping using a set for constant lookup
    while pos < len(text) and text[pos] not in ' \t\n\r\f':
        pos += 1
    return pos
```

This approach uses a set to quickly check if the current character is a whitespace, which can significantly improve performance when dealing with large inputs. The `not` operator is used to negate the membership test, reducing the number of comparisons needed.
