A more efficient way to skip whitespace is by using a set for character checks in `_skip_ws`. This avoids iterating through a list of all characters, which can be slow and resource-intensive. The current implementation uses the `in` operator with a list of characters, which has an average time complexity of O(n), where n is the length of the string. Using a set allows us to check if a character exists in constant time, which reduces the overall time complexity of the function.
