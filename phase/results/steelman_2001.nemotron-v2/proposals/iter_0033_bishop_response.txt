Replace the manual validation loops for detecting valid JSON escape sequences with a single `in` check against a precomputed frozenset of all allowed escape strings (e.g., `"\\n"`, `"\\r"`, `"\\t"`, `"\\u"` plus the valid hex codes). This turns each validation into an O(1) set‑lookup instead of a per‑character loop, speeding up the parser without altering its correctness.
