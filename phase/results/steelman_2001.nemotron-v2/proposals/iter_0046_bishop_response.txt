In _parse_number the loop repeatedly tests `text[pos] in _DIGIT_CHARS_SET`, which performs a set lookup for each character. Since the set contains only the ten digit characters, replacing that test with a simple range check `'0' <= text[pos] <= '9'` will avoid the set lookup entirely, making the parsing faster without changing behaviour. This change is confined to the digit‑parsing loop in _parse_number and does not affect any other part of the code.
