Swap the list `_DIGIT_CHARS` for a set `_DIGIT_CHARS_SET` and remove the list, updating every `text[pos] in _DIGIT_CHARS` check to use `_DIGIT_CHARS_SET`. Since set lookups are O(1) instead of the O(k) cost of a list, the numeric‑parsing loop in `_parse_number` becomes significantly faster. The change is safe because the set contains exactly the same characters as the original list.
