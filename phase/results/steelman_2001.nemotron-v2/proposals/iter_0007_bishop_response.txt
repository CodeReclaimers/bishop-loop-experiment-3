Modify the `_parse_string` function to collect characters in a Python list instead of building the result string with repeated concatenation, and at the end join the list into a single string, which avoids the O(n²) cost of repeated string building. Additionally, treat the list as a mutable buffer for escaped characters, so that the escape‑sequence expansion updates the list rather than repeatedly reallocating strings. This change keeps the output identical while reducing the time complexity of string construction.
