Modify the string‑building logic in `_parse_string` (and the similar handling in `_parse_unescaped_control`) to collect characters in a list or `io.StringIO` and join/append them at the end instead of repeatedly concatenating strings, which cuts the cost from quadratic to linear. This change keeps the output a string but avoids the O(n²) rebuilding of a new string on every character, while the parser still returns the correct value.
