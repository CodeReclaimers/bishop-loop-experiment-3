Replace all uses of `_DIGIT_CHARS_SET` in `_parse_number` with calls to the built‑in `str.isdigit()` method, which performs an O(1) digit check without the overhead of iterating over a set; this eliminates the repeated creation of the set (even though it is already created once) and reduces the constant‑time overhead of the membership test. The changes include the initial digit check, the loop that consumes consecutive digits, and the leading‑zero validation, all of which now rely on a single, fast O(1) lookup per character.
