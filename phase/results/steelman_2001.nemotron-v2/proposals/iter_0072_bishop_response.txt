Modify the condition that checks whether the current character is a digit in the `_parse_number` function to use the built‑in string method `c.isdigit()` instead of a membership test against `_DIGIT_CHARS_SET`. Since `c.isdigit()` is implemented in C, it avoids the Python‑level loop over the set and performs the same check with O(1) speed and no extra memory.
