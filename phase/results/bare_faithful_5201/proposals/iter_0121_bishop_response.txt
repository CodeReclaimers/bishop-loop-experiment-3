To make the JSON parser faster, we can optimize the parsing of numbers by directly converting them from strings to floats or integers, rather than using `float(text[pos:])` or `int(text[pos:])`. This avoids the overhead of string-to-number conversions that are time-consuming and require additional memory. We can achieve this by defining a helper function `_parse_number` that parses numbers from strings character-by-character, checking for digit characters, and handling floating-point notation if needed. The rest of the code remains largely unchanged, with only the `parse` function calling `_parse_number` to handle number parsing.
