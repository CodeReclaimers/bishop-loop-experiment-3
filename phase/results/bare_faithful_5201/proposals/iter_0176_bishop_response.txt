To optimize the JSON parser, we can precompute a mapping from each possible character to its class (e.g., whitespace, digit, letter). This reduces the number of string operations and improves performance by avoiding the use of `ord()` on each character. We can then use this mapping in our `_skip_ws` function and other parsing functions to quickly determine whether a given character is part of a specific category.

This change significantly reduces the time complexity of _skip_ws, which currently scans through the entire string until it finds non-whitespace characters. By precomputing the class mappings, we can efficiently skip past whitespace characters in constant time.
