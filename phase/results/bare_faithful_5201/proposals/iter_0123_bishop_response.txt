To improve the speed of the JSON parser, we can use a different strategy for parsing numbers. Instead of scanning character-by-character to check for digits and decimal points, we can convert the entire number string into an integer or float directly using Python's built-in functions. This approach reduces the overhead of repeated character checks and makes the parsing process more efficient.

Here's how you can implement this change:

```python
def _parse_number(text: str, pos: int) -> tuple[float | int, int]:
    # Convert the entire number string into an integer or float directly
    return float(text[pos:]), pos + len(text[pos:])
```

Explanation:
1. We replace the existing `_parse_number` function with a new one that uses Python's `float()` function to convert the entire number string into a floating-point number.
2. This approach eliminates the need for repeated character checks, resulting in faster parsing times.
3. The conversion to a float is straightforward and efficient, leveraging Python's built-in capabilities to handle numbers accurately.
