CRITIQUE: The suggestion to use `text.translate` with a translation table mapping whitespace chars to `None` is unworkable because `translate` removes characters but doesn't advance a position pointer — it returns a new string with characters removed, not a new position index. This approach would break the parser's position-tracking logic. Additionally, `translate` is not a drop-in replacement for the while loop since it doesn't return the new position, and the performance benefit would be negated if the entire string were translated and then re-scanned.

STEELMAN: The steelman is to precompute a translation table that maps whitespace characters to a single sentinel character (e.g., `'\x00'`), then use `str.translate` to replace all whitespace with that sentinel, and finally advance the position pointer by counting sentinel characters in the translated string. This preserves the core idea of batch processing while maintaining correct position tracking.

def _skip_ws(text: str, pos: int) -> int:
    # Use translate to batch-replace whitespace with sentinel, then count sentinels
    if pos >= len(text):
        return pos
    # Translate all whitespace to sentinel character
