In _skip_ws replace the character‑by‑character while loop that tests each position against _WS_CHARS with a single str.translate call that maps every whitespace character to a distinct sentinel, using a pre‑computed table so the skip is performed in one C‑level pass. This removes the per‑iteration Python loop and leverages the highly‑optimized built‑in translation, making whitespace skipping substantially faster while preserving the same result.
