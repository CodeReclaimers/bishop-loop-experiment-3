Replace the set membership checks `c in _WS_CHARS` and `c in _DIGIT_CHARS` with a pre‑computed 256‑byte boolean lookup table `_WS_TABLE` (and a similar `_DIGIT_TABLE`). This gives each character a constant‑time O(1) lookup instead of hashing the set, speeding up `_skip_ws` and the digit‑parsing loop while keeping the parsing logic identical.
