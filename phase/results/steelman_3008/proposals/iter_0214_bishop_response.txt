Replace the set‑based character‑membership checks with a 256‑element lookup table that maps each byte value to a boolean flag, so that every character test becomes a direct table lookup instead of a set iteration. This change speeds up the loops in _skip_ws, _parse_value, _parse_number, _is_hex4 and any other place that currently uses `c in _WS_CHARS`, _DIGIT_CHARS or _HEX_CHARS. The table preserves correctness because it evaluates exactly the same membership logic without altering the logic.
