Replace the iterative while‑loop in _skip_ws with a single call to text.find that searches forward from pos for the next character not in _WS_CHARS and returns its index (or len(text) if none is found). This eliminates the per‑character membership checks and jumps directly to the position of the next non‑whitespace character, which is the dominant cost in the parser. The change is correct because it yields the same index as the original loop, only without the unnecessary loop overhead.
