In _skip_ws, replace the current while loop that checks each character against _WS_CHARS with a single call to the built‑in str.find to locate the next non‑whitespace character, which skips entire runs of whitespace without iterating each character. This eliminates per‑character set membership lookups and reduces overhead, making the function O(k) instead of O(k·c) where c is the character set size. The correctness remains unchanged because the function still returns the index of the first non‑whitespace or the end of the string.
