Replace the current `_skip_ws` implementation that iterates over each whitespace character with a single call to `text.find(''.join(_WS_CHARS), pos)` (handling the case where the search returns -1) to skip all consecutive whitespace in one operation. This turns the linear scan into an O(1) operation per call, which is faster while preserving exact whitespace‑skipping behavior. The rest of the parser remains unchanged.
