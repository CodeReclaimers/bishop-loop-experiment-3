Optimize whitespace skipping by using `text[pos:].lstrip(' \t\n\r')` instead of a regex, which can be faster for large inputs due to the reduced overhead of string slicing and regular expression matching.

This approach involves checking if the character at position `pos` is a whitespace character. If it is, the function returns `pos + len(text[pos:].lstrip(' \t\n\r'))`. This allows us to skip over multiple consecutive spaces, tabs, newlines, or carriage returns in a single operation instead of repeatedly calling Python's built-in string methods like `isspace()` and `split()`.
