To improve performance in `json_parser.py`, we can optimize the way numbers are scanned character-by-character. Instead of using a regex to match the entire number, we can use a loop that iterates through the string and checks for valid digits and optional decimal points. This approach reduces the time complexity from O(n) to O(max_number_of_digits + 1), where `max_number_of_digits` is the maximum length of any number in the JSON data.
