This avoids repeatedly checking if a character is whitespace, which reduces overhead and improves performance significantly for large inputs. The modified `_skip_ws` function would look like this:

```python
def _skip_ws(text: str) -> int:
    return sum(1 for c in text[pos:] if c not in _WS_CHARS)
```
