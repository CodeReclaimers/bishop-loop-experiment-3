One specific change to try in `json_parser.py` is to use a regular expression to skip whitespace instead of a loop. This should improve performance by reducing the overhead of string manipulation and character comparison. The regular expression approach would look something like this:

```python
import re

def _skip_ws(text: str, pos: int) -> int:
    return pos + len(re.match(r'\s+', text[pos:]).group(0))
```

This uses the `re` module to match one or more whitespace characters at the current position and returns the length of the matched string.
