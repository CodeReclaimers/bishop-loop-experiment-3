Replace every occurrence of a manual character‑by‑character whitespace check (e.g., `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1`) with a single call to `_skip_ws(text, pos)`, which consumes all whitespace in one regex match and updates `pos` to the end of the matched substring. This eliminates the per‑character loop overhead while preserving the same semantics, because `_skip_ws` already uses the pre‑compiled `_WS_PATTERN` to skip whitespace in O(1) steps. The speed gain comes from using the compiled regex engine instead of Python’s O(n) iteration.
