Replace the calls to _WS_PATTERN.span(text, pos)[1] in parse and _parse_value with the dedicated _skip_ws function, which performs the same whitespace‑skipping logic using a simple character‑by‑character loop instead of invoking the regex engine each time. This removes the costly per‑skip regex computation while keeping the behavior equivalent, and you can also apply _skip_ws to the whitespace‑skipping portions inside _parse_object for the same gain.
