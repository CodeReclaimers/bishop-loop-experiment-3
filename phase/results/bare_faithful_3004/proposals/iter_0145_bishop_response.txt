Replace the manual character‑by‑character digit and decimal/exponential scans inside `_parse_number` with a single call to the pre‑compiled `_NUMBER_PATTERN.match` that returns the full token in one step, then set `pos = match.end()`. This avoids the per‑character `while` loops and `ord` checks, letting the regex engine handle the token extraction in compiled C code, which is much faster while preserving the same parsing logic.
