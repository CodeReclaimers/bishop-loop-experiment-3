Replace the repeated calls to the compiled regex `_WS_PATTERN.match` inside `_skip_ws` and the object/array parsing loops with a direct character‑by‑character check using the pre‑computed `_WS_CHARS` set, which increments `pos` incrementally without invoking regex each time. This eliminates the overhead of regex pattern matching for whitespace and speeds up white‑space skipping while keeping the same behavior.
