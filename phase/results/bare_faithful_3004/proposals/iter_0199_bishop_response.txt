Replace the per‑character whitespace‑skipping loops such as `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1` with a single call to `_WS_PATTERN.match(text, pos).end()` to advance the index directly to the next non‑whitespace character. This eliminates repeated O(1) membership checks inside the string and instead uses the compiled regex that already scans the whole whitespace run in C. The performance gain is primarily from minimizing Python‑level loop overhead while preserving correctness.
