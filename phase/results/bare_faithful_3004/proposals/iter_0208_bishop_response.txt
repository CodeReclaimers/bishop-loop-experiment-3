Replace the `_skip_ws` function with an in‑line while‑loop that advances `pos` as long as the character at that position is in `_WS_CHARS`, instead of calling the regex `_WS_PATTERN.match`. This eliminates the O(n) regex call for each whitespace segment and reduces the per‑character overhead to a simple constant‑time check. The rest of the parser already uses a similar while‑loop in `parse`, so the change keeps correctness while removing unnecessary regex work.
