Replace the `_skip_ws` function so it skips whitespace by incrementing `pos` while `text[pos]` is in the `_WS_CHARS` set instead of using a compiled regex to find the next match. This eliminates the overhead of the regex engine and directly leverages the constant‑time character‑membership check that the parser already uses elsewhere. The change keeps correctness intact because it only moves `pos` past any whitespace characters.
