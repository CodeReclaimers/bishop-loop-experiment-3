Replace the manual index‑based traversal in `_parse_number` with a single call to the pre‑compiled `_NUMBER_PATTERN.match(text, pos)` to obtain the end index of the whole number token, then convert the slice `text[start:end]` to `int` or `float` and return that value together with `pos = end`. This avoids repeatedly checking each character and the regex match is performed in C, giving a noticeable speed boost while keeping the same tokenisation logic.
