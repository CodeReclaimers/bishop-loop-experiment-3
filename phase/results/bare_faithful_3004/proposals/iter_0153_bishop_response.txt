Replace the manual `while` loops that skip whitespace in `_parse_value`, `_parse_object`, `_parse_array`, `_parse_string`, and `_parse_bool` with calls to the pre‑compiled `_WS_PATTERN.match` method, which consumes all whitespace characters in a single operation. This eliminates the per‑character checks and leverages the fast compiled regex engine, while still advancing `pos` to the correct index returned by the match. The number parsing already uses `_NUMBER_PATTERN.match`, so no change is needed there.
