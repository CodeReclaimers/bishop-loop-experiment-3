Replace the regex‑based whitespace‑skipping calls in `parse`, `_skip_ws`, and the whitespace loops inside `_parse_value`, `_parse_object`, `_parse_array`, and `_parse_string` with a simple `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1` loop, which eliminates regex compilation and matching overhead while still consuming all leading whitespace. This change is fast because it uses a fast O(1) set membership check instead of regex engine work.
