Replace the sequential while‑loop based `_skip_ws` calls with a single regex query that directly returns the index of the next non‑whitespace character, e.g. using `re.search(r'[^ \t\n\r]', text, re.IGNORECASE).start(pos)`, so whitespace consumption no longer relies on Python iteration. This leverages the already compiled whitespace pattern to jump to the next token in constant time, eliminating the overhead of looping over each whitespace character. The rest of the parser can keep using the returned index directly.
