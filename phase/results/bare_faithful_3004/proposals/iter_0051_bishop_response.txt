Replace the regex‑based whitespace‑skipping calls in _skip_ws and the whitespace loops inside _parse_value and _parse_object with direct index increments using the _WS_CHARS set, removing the pattern creation altogether. This eliminates the overhead of matching and advancing via a compiled regex, letting the O(1) set lookup handle each character in constant time. The parser will still skip whitespace correctly while gaining a measurable speedup.
