Replace the per‑character whitespace skips in `_parse_value`, `_parse_object`, `_parse_array`, `_parse_string`, and any other function that manually increments `pos` while `text[pos] in _WS_CHARS` with a single call to `_WS_PATTERN.match(text, pos).end()`. This skips all consecutive whitespace characters in one go, eliminating the loop overhead while still advancing `pos` correctly. The change keeps the logic correct because the regex matches only whitespace, so `pos` ends up at the next non‑whitespace character.
