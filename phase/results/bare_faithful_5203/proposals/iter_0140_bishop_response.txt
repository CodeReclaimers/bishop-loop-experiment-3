To speed up the JSON parser, a significant optimization opportunity is to eliminate the use of `pos + len(text[pos:].lstrip(' \t\n\r'))` in `_skip_ws`. This operation repeatedly scans the string starting from each position, which can be costly and inefficient. Instead, we can maintain a pointer that always points to the first non-whitespace character in the input. We can then use this pointer to directly move forward when parsing values, avoiding unnecessary slicing operations.

This approach reduces the number of substring operations by approximately half for strings with many leading spaces or tabs, resulting in a significant speedup.
