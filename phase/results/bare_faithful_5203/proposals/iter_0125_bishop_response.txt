To optimize the `json_parser.py` for speed without compromising correctness, we can leverage a streaming approach where the JSON data is processed character by character as it's parsed. This allows us to avoid loading the entire JSON document into memory and reduces the time required for parsing large inputs.

One specific change could be to use a generator function that yields each parsed value as it's read from the input string. This would eliminate the need to build up an intermediate data structure (like lists or dictionaries) and instead directly yield the values. The generator function can then be used in a loop to handle the parsed data as it comes in. This approach avoids unnecessary memory allocation and processing overhead, resulting in faster parsing times while maintaining the correctness of the JSON parser.
