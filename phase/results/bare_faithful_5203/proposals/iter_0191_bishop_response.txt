To speed up the JSON parser, we can optimize the whitespace skipping by using a generator expression instead of `lstrip`. This approach avoids creating a full slice of the string when checking for leading whitespace characters, which could be computationally expensive.

Here's how you can implement this change:

```python
def _skip_ws(text: str, pos: int) -> int:
    return next((i for i, c in enumerate(text[pos:]) if not c.isspace()), len(text))
```

This approach uses a generator expression to iterate over the string starting from `pos`, and it stops when it finds a non-whitespace character. The index of this character is then returned as the new position. This method avoids creating a full slice of the string, which can be significantly faster for large input strings.
