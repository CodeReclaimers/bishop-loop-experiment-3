To speed up the JSON parser, we can optimize the whitespace skipping by using a generator expression instead of a loop. This eliminates the overhead of calling `len` on the string and reduces the number of function calls. Here's how you can modify the `_skip_ws` function:

```python
def _skip_ws(text: str, pos: int) -> int:
    return pos + len(list(filter(lambda c: c in ' \t\n\r', text[pos:])))
```

This approach works as follows:
1. The `filter` function is used to create a generator that yields only the characters in the set `' \t\n\r'`.
2. The `list` function converts this generator into a list.
3. Since lists are iterable, we can directly use the `len` function on this list.

This change reduces the number of iterations and function calls, resulting in faster parsing times.
