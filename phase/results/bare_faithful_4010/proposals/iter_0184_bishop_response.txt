One potential optimization is to use a more efficient way to handle whitespace skipping by using a regular expression instead of a custom loop in `_parse_value`. This can be done by replacing the `while pos < len(text) and text[pos] in _WS_CHARS` loop with a call to `re.match(r"\s+", text)` which will return the starting index of the first whitespace if found, or None otherwise. This approach can reduce the number of Python function calls made and potentially improve performance.
