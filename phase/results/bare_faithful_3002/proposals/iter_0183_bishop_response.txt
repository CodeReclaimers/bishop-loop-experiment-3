Replace the repeated calls to `_skip_ws`, which performs a full regex match each time, with a binary‑search lookup into a pre‑computed list of whitespace token boundaries generated once at import time. The list contains the start and end indices of all whitespace runs in the input string, allowing the parser to jump straight to the next non‑whitespace position without invoking a regular expression. This eliminates the overhead of calling and matching a regex repeatedly while preserving the exact same behavior.
