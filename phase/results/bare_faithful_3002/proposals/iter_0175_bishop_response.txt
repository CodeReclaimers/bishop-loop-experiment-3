Replace the linear `while` loops that skip whitespace with a single call to a pre‑compiled regular expression such as `WS_RE = re.compile(r'\s+')` and then use `pos = WS_RE.search(text, pos).end()` to jump directly to the next non‑whitespace character, which is O(1) per iteration and avoids repeated `in` checks. This keeps the same correctness because the regex matches exactly the same set of characters.
