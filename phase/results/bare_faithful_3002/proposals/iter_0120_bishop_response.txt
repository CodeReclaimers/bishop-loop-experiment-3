Replace the calls to `re.match(r'\s*', text, pos)` in `parse` and `_skip_ws` with the simple `while pos < len(text) and text[pos] in " \t\n\r": pos += 1` loop that already exists in `_skip_ws`, since the regex engine is unnecessary and much slower than a direct character check. This avoids the overhead of building a regex match object each time and uses a fast Python loop that directly skips whitespace.
