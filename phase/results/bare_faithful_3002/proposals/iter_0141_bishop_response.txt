Replace the two calls to `re.match(r'\s*', text, pos)` in `parse` and `_skip_ws` with a simple while‑loop that increments `pos` while `text[pos]` is one of `" \t\n\r"`. This eliminates the overhead of creating a new regex object and matching each time. The loop uses the same set of whitespace characters, so correctness is unchanged, but the parser gains speed by avoiding regex execution overhead.
