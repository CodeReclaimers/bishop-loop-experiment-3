Modify the `_skip_ws` function to locate whitespace segments using a compiled regular expression and its `find` method rather than scanning character‑by‑character in a while loop. Replacing the incremental loop with a single call to `re.finditer(r'\s*', text, pos)` that returns the end index of the next whitespace block gives a much faster, O(1) lookup for skipping whitespace.
