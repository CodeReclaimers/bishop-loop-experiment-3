Replace the per‑character whitespace loops in `parse`, `_skip_ws`, `_parse_value`, and all the inner while‑loops that advance `pos` by one with a single call to `re.match(r'\s+', text, pos)` that consumes all consecutive whitespace at once, then returns the new position. This avoids the cumulative cost of checking each character individually and is still correct because the regex matches exactly the same whitespace characters.
