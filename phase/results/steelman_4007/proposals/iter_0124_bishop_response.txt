To speed up the JSON parser, we can optimize the whitespace skipping step by using a Python `re` module to compile the regex pattern only once and then reusing it multiple times throughout the function. This reduces the overhead of parsing the regex each time through the loop. The updated version of `_skip_ws` would look something like this:

```python
import re

# Compile the regex pattern for whitespace once at the start of the file
_WS_REGEX = re.compile(r"\s+")

def _skip_ws(text: str, pos: int) -> int:
    # Use the compiled regex to skip all leading whitespace in one operation
    match = _WS_REGEX.match(text, pos)
    if match:
        return match.end()
    return pos
```

This change makes the `parse` function faster by avoiding unnecessary re-parsing of the regex pattern each time through the loop.
