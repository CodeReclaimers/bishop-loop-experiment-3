The approach also fails to address the core issue of character-by-character scanning in number parsing, which is already optimized via set membership checks.

STEELMAN: A better approach would be to use a hybrid strategy where we pre-scan number and string portions using efficient string methods or built-in parsing functions (like `int()` and `float()`) when possible, and only fall back to character-by-character checks for edge cases or when needed for position tracking. This preserves the performance benefits of avoiding repeated scanning while maintaining correctness and avoiding regex overhead.
