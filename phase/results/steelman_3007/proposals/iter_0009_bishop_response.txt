Replace the while‑loop in `_skip_ws` with a single C‑level call to `text.find_first_not_of(' \\t\\n\\r', pos)`, which directly returns the index of the next non‑whitespace character without iterating character‑by‑character. This eliminates the Python‑level loop and its O(n) overhead for each whitespace skip. The rest of the parser can stay unchanged because the result is the same index where the next token begins.
