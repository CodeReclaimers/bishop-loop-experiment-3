Replace the per‑call `_skip_ws` implementation with a pre‑computed lookup table that stores, for each index, the position of the next non‑white‑space character in the input string; the function then simply reads from that table instead of scanning the string character by character. This eliminates the repeated `while` loop and `in` set checks, turning each whitespace skip to an O(1) array lookup while preserving correctness.
