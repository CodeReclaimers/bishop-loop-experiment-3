Pre‑compute a `next_non_ws` array that stores, for each position, the index of the next character not in `_WS_CHARS`; then replace `_skip_ws` so it returns that value directly via a simple table lookup instead of checking each character in a loop. This eliminates per‑character whitespace checks in object and array parsing, reducing work from O(k) to O(1) per skip and keeping correctness unchanged.
