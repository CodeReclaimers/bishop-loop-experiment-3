Replace the current `_skip_ws` implementation that loops over each whitespace character with a single call to the compiled regex `_WS_RE.search`, advancing `pos` to the end of the matched whitespace sequence (`pos = _WS_RE.search(text, pos).end`). This eliminates the per‑character loop, reducing the overhead from O(k) iterations to a single O(k) search that is handled internally in C, thus speeding up whitespace skipping while keeping the same behavior.
