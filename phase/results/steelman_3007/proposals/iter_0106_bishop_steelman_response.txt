CRITIQUE: The suggestion to use binary search over pre-computed indices for whitespace skipping is fundamentally flawed because it assumes a static list of non-whitespace positions, which would require expensive recomputation for every call. It also ignores that the typical case involves only a few whitespace characters, making binary search overhead outweigh any benefits. Additionally, the approach breaks the incremental nature of parsing where whitespace is usually skipped in small chunks.

STEELMAN: A better approach is to precompute a list of indices where whitespace characters begin and end, then use binary search to quickly locate the next non-whitespace character. This avoids the linear scan while still being practical for the common case where whitespace runs are short. The key is to compute this index list once per input and reuse it, rather than rebuilding it for each call.

def _build_ws_indices(text: str) -> list[int]:

        if is_ws != in_ws:
