CRITIQUE: The suggestion to replace the while-loop in `_skip_ws` with a regex span call is flawed because `re.compile(r'\s*')` will match zero or more whitespace characters starting at the current position, not the next non-whitespace character. Using `span()` would give the range of the matched whitespace, not the position of the first non-whitespace character after it. Additionally, this approach would likely be slower than the current O(1) lookup in a set for each character.
