Replace the current while‑loop that manually skips whitespace with a single call to the pre‑compiled `_WS_RE` regex, letting the engine jump directly to the next non‑whitespace character. This eliminates the repeated O(1) set‑lookup loop and reduces function call overhead while achieving the same result. The only change is in `_skip_ws`, which now returns `_WS_RE.match(text[pos:]).start() + pos` instead of incrementing `pos` index‑by‑index.
