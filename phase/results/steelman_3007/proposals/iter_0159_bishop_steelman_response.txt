CRITIQUE: The suggestion to replace the while-loop with a precomputed skip table is unworkable because it would require building a skip table for every possible input string, which is infeasible due to memory and time complexity. It also fails to account for the dynamic nature of input strings and would not scale to large inputs without prohibitive overhead.

STEELMAN: A better approach is to precompute a skip table for each starting position by scanning ahead until the next non-whitespace character, storing only the next valid index. This allows O(1) lookup per call to `_skip_ws` by indexing into the precomputed table, avoiding repeated scanning while maintaining correctness and scalability.

# Precomputed skip table for whitespace
def _build_skip_table(text: str) -> list[int]:
    n = len(text)
    skip_table = [0] * n
    i = n - 1
    while i >= 0:
        if text[i] in _WS_CHARS:
            if i == n - 1:
                skip_table[i] = n
            else:
                skip_table[i] = skip_table[i + 1]
        else:
            skip_table[i] = i + 1
        i -= 1
    return skip_table
