Replace the per‑character `_skip_ws` loop in `parse` and `_parse_value` with a single call to `_WS_RE.sub('', text)` at the beginning and end of the parse, and within `_parse_value` use `_WS_RE.span(pos)` to jump over whitespace without iterating each character. This avoids O(N) character checks per skip and reduces the number of loop iterations dramatically while still consuming only valid whitespace. The result is a faster parser that still correctly handles all JSON whitespace.
