Replace the manual `_skip_ws` loops in `_parse_value` and related functions with a single call to `_WS_RE` to directly jump to the next non‑whitespace character, eliminating per‑character set checks and string slicing. This leverages the compiled regex’s internal state to skip whitespace in one operation instead of iterating character by character. The approach maintains correctness because the regex matches exactly the same whitespace characters defined in `_WS_CHARS`.
