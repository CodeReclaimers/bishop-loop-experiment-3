In _skip_ws, replace the character‑by‑character loop that checks _WS_CHARS with a single call to the compiled regular expression, advancing pos to _WS_RE.start(pos) + _WS_RE.end(pos). This skips any consecutive whitespace characters in one step, eliminating the repeated O(1) lookups and greatly reducing the number of iterations. Because the regex matches the same pattern as the set check, the parser remains correct.
