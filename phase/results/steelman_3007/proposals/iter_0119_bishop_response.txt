Replace the naive `_skip_ws` loop with a precomputed skip table generated once per input string and passed to `_skip_ws` via the optional `skip_table` argument, so each whitespace skip becomes an O(1) lookup instead of an O(k) character‑by‑character scan. This eliminates the repeated linear scans of the same whitespace characters across the parser, while the same correctness logic is preserved through the existing table logic.
