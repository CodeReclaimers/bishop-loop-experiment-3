Replace the Python‑level set look‑ups for whitespace, digits, and hexadecimal characters with the built‑in string methods isspace, isdigit, and isalnum, which are C‑level operations and avoid Python object creation. This eliminates the manual step‑wise loops in _skip_ws and _parse_value that currently manually advance the index, letting Python’s C‑optimized string functions do the work.
