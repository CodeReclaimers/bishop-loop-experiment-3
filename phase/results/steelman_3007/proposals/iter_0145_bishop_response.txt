Replace the current _skip_ws function with a direct lookup into a pre‑computed integer skip table that stores, for each position, the index after the next whitespace run, and call it with pos = skip_table[pos] instead of looping over characters. This eliminates the O(n) character‑by‑character scan and the set‑membership checks, turning whitespace skipping into O(1) work per jump. The rest of the parser can keep using the same table to advance positions instantly.
