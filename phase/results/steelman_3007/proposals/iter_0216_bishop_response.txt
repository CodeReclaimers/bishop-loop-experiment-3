Replace the character‑by‑character whitespace checks in `_parse_value` and the surrounding parsing loops with a single jump using the pre‑computed `_build_skip_table`; the function then returns the next non‑whitespace index directly instead of iterating through each whitespace character. This eliminates the repeated O(1) set lookups and saves the cost of the while‑loop condition checks while preserving exact position tracking. The overall parse proceeds by always advancing to the next token in one step, which is the primary source of speed loss.
