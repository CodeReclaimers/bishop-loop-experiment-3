Using `search()` would find the first match of `\s*` starting at `pos`, which could be zero-length and thus not advance the position. Additionally, this approach would not handle the case where the regex engine has to backtrack or where the input is very long, potentially degrading performance compared to the simple O(1) set membership checks.
