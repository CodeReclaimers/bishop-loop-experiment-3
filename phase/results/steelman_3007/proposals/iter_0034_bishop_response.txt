Replace the repeated per‑character whitespace checks in `_skip_ws` with a single call to `re.sub` that removes all whitespace from the input string before parsing begins. This reduces the O(n) loop that walks the string to a fast C‑level regex substitution, eliminating the need for O(1) set lookups and while‑loop iterations.
