CRITIQUE: The suggestion to use binary search on a pre-computed list of non-whitespace positions is fundamentally flawed because it doesn't account for the fact that whitespace skipping is typically done in a forward direction from a given position, not as a one-time preprocessing step. Additionally, maintaining a list of all non-whitespace positions would require O(n) space and would be inefficient for small inputs or inputs with few whitespace characters.
STEELMAN: A better approach is to precompute a lookup table of the first non-whitespace character position for each possible starting position, allowing constant-time skipping by indexing into this table. This preserves the core idea of eliminating the Python loop while maintaining correctness and performance characteristics.

def _build_skip_table(text: str) -> list[int]:

    skip_table = [0] * n
    last_non_ws = n
