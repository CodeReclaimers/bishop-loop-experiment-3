Replace the per‑character whitespace‑skipping loop in `_skip_ws` with a single pass that records only non‑whitespace positions, then use binary search to jump directly to the next token; this eliminates repeated membership checks and string lookups. By caching the positions, the parser can advance pointers without scanning each whitespace character individually, which is the core of the current inefficiency. This change keeps the same O(1) correctness while dramatically reducing the number of iterations per parse.
