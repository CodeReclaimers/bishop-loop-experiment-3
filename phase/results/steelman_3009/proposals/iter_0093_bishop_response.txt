In _skip_ws, replace the Python loop that advances pos character‑by‑character with a single call to text[pos:].translate(_WS_TRANSLATE_TABLE).count('\0') to compute the number of whitespace characters to skip at once; the translation table maps every whitespace character to a null byte, so the operation runs in compiled C time and avoids Python‑level iteration. This eliminates the per‑character overhead of the while loop while preserving exact whitespace‑skipping semantics.
