STEELMAN: A better approach would be to use `re.match(r'\s*', text, pos)` which matches zero or more whitespace characters starting exactly at `pos`, and then return `pos + match.end()` to get the index of the first non-whitespace character. This avoids the Python loop and lets the C-level regex engine do the work in one pass, while correctly handling the position semantics.
