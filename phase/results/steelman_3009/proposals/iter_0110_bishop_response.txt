Precompute a static list of all non‑whitespace character indices in the input at the start of `parse`, then replace the character‑by‑character `_skip_ws` loop with a binary search into that list to jump directly to the next token. This eliminates the per‑character checks and the Python‑level while loop, turning whitespace skipping into an O(log n) operation instead of O(m) where m is the number of skipped characters. The rest of the parser uses the adjusted index, ensuring the same final `pos` value is reached.
