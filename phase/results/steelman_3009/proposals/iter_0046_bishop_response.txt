Replace the per‑character whitespace‑skip loop in `_skip_ws` with a single `text.find` call that returns the index of the next non‑whitespace character, so the parser jumps over all whitespace in one C‑level pass instead of looping through each character in Python. This eliminates the O(n) Python overhead of the manual `pos += 1` increments and the set‑lookup‑based character checks in `_parse_value` that already use the pre‑computed `_WS_CHARS` set.
