Replace the character‑by‑character while‑loop in _skip_ws with a single call to text.find('\s', pos) that returns the index of the next whitespace character, then advance pos to that index plus one (or to len(text) if none is found). This eliminates the repeated per‑character checks and reduces the number of iterations per whitespace skip, making the parser significantly faster while preserving the same whitespace‑skipping behavior.
