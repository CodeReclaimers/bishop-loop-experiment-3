Replace the while‑loop in _skip_ws with a single text.find(' \t\n\r', pos) call that returns the index of the next non‑whitespace character (or len(text) if none is found). This skips all whitespace in one operation instead of iterating character‑by‑character. Since whitespace is only ever ' ' or '\t' or '\n' or '\r', using find is both faster and simpler.
