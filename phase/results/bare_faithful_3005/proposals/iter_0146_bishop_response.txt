Remove the helper function `_is_hex4` and inline its logic within the array parser, so the parser checks the slice length and hex characters directly instead of invoking a function call. This eliminates the function‑lookup overhead and the repeated `all(c in _HEX_CHARS for c in s)` evaluation, which is the dominant cost in handling Unicode escapes. The parser will still validate the same conditions, preserving correctness while speeding up execution.
