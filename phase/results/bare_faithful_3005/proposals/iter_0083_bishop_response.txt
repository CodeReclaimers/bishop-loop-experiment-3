Replace the binary‑search based _skip_ws implementation with a simple linear scan that moves the current position forward to the next whitespace index in a pre‑computed list of all whitespace positions, computed once at parse time. This avoids the O(log n) binary‑search cost of each call and the overhead of repeatedly building the whitespace list, while still correctly skipping all whitespace characters. The change modifies only the logic inside _skip_ws to use the cached list and a global progress pointer.
