Replace the per‑character while loop in _skip_ws with a single call to _WS_PATTERN.search (or match) to locate the next non‑whitespace character, returning its index directly instead of incrementing one position at a time. This eliminates the overhead of repeatedly checking each character and reduces the function to a low‑level string operation. The change keeps the same logic for skipping whitespace while using the compiled regex pattern for constant‑time locating.
