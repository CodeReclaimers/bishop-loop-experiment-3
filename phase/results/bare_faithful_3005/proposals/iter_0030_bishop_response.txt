Replace the `_skip_ws` implementation that currently calls `re.compile(r'\s*')` with a direct while‑loop that increments `pos` while `text[pos]` is a space, tab, newline or carriage‑return. This removes the overhead of compiling and invoking a regular expression for every skip, letting the function perform a simple index check instead. The change is safe because the loop skips exactly the same set of whitespace characters.
