Pre‑compute a list of all whitespace character positions in the input string at the start of parsing, then replace the linear `_skip_ws` loop with a binary search using `bisect_left` to locate the next non‑whitespace index. This reduces the per‑skip cost from O(k) characters to O(log W) look‑ups, which is far faster for long inputs. The rest of the parser remains unchanged, preserving correctness.
