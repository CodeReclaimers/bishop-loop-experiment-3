Replace the current `_skip_ws` implementation, which uses multiple `text.find` calls, with a single call to the compiled `_WS_PATTERN.search(text, pos).end()`. This lets Python’s regular‑expression engine jump to the first non‑whitespace character in one operation, eliminating the loop and the string searches that dominate the function. The change keeps the same semantics while dramatically reducing the time spent in whitespace skipping.
