Replace the `_skip_ws` loop that checks each whitespace character (` ' \t\n\r `) with a single call to `text.find('\s', pos)` to locate the next whitespace character, then advance the index by one. This reduces the per‑character overhead to a single string search, which is faster while still correctly skipping whitespace. This change targets only the whitespace‑skipping logic and the rest of the parser remains unchanged.
