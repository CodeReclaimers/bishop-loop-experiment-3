Replace the manual digit‑by‑digit, dot‑and‑exponent checks in _parsenumber with a single regular‑expression match that parses both integers and floats at once, and then return the numeric value via that match; this eliminates the repetitive while loops and conditionals that scan each character individually. The regex engine handles the whole token in C‑level code, which is orders of magnitude faster than Python’s explicit traversal. This change keeps correctness because the regex validates the same numeric format.
