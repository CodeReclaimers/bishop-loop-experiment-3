One potential optimization is to use a generator expression instead of list comprehension for string concatenation in `_parse_string`. The current implementation uses `join`, which creates a new list and then joins it into a string. This can be slow especially if the string concatenation involves many small strings.

Instead, we can use the `yield` keyword inside the loop to yield each character as it is encountered, which avoids creating intermediate lists. This way, we create the final string only after all characters have been processed.
