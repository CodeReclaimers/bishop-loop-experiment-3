To make the JSON parser faster, one potential optimization could be to use a more efficient way to skip whitespace. Currently, we are using `re.compile` to compile a regex pattern for skipping whitespace, which can lead to performance issues if the text contains many consecutive spaces or tabs. One approach to speed up this step is to manually scan through the string and count the number of non-whitespace characters until the next one is encountered. This would allow us to avoid compiling a regex every time we parse a JSON value, resulting in faster parsing times.
