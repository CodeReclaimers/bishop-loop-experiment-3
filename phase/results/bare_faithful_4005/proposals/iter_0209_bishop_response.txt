To improve the performance of the JSON parser in `json_parser.py`, we can consider using a more efficient approach to parsing numbers. Specifically, instead of converting strings to floats or integers, we can directly parse them from the input string without creating new objects. This will eliminate the overhead of string conversions and improve the speed of the parsing process.

Here's how the change can be implemented:

1. **Parse Numbers Directly**: Instead of using `int()` or `float()`, we can use built-in functions like `ord()` to convert characters directly to integers and calculate numbers manually.

2. **Efficient Number Parsing Logic**: We can handle the parsing logic for floating-point numbers more efficiently by keeping track of the sign, decimal point, and exponent separately. This will avoid unnecessary string conversions and improve the speed of the parser.

3. **Avoid Redundant Checks**: We can remove redundant checks for hexadecimal digits to directly parse them when encountered.

By implementing these changes, we can significantly reduce the number of intermediate objects created during parsing, which should result in faster execution times while maintaining the correctness of the JSON parsing algorithm.
