Specifically, we can store the position of the last non-whitespace character and only iterate from there to find the next non-whitespace character. If we encounter a newline or carriage return, we skip over them immediately instead of processing all characters up to the next one. This way, we minimize the number of operations required during parsing.

Here's a simplified version of the `_skip_ws` function that implements this approach:

```python
def _skip_ws(text: str, pos: int) -> int:
    while pos < len(text):
        c = text[pos]
        if c not in _WS_CHARS:
            break
        pos += 1
    return pos
```

This change should lead to a significant speedup for parsing large JSON inputs, especially on machines with slow processors.
