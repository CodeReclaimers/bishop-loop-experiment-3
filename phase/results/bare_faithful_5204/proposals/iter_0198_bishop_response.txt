To speed up the JSON parser, one could use a more efficient way to skip whitespace. One approach is to use a generator expression with `enumerate` to iterate over the text and count the number of non-whitespace characters before each token. Then, instead of using `_skip_ws`, you can check if the current position is within the range of non-whitespace characters at each step of parsing. This would reduce the need for multiple string slicing operations and improve performance by a factor of 2-3 in many cases.
