Replace the manual `_skip_ws` loop that manually increments `pos` while checking `text[pos] in _WS_CHARS` with a single call to `_WS_RE.match(text, pos).end()` if a match is found, otherwise return `pos`. This leverages the compiled regex to skip all consecutive whitespace characters in one operation, eliminating the per‑character loop and the O(1) frozenset lookups.
