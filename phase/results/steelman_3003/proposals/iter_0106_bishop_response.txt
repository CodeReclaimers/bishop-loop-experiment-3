Replace the while‑based `_skip_ws` implementation with a single call to a regex search that finds the next non‑whitespace character, e.g., `pos = re.search(r'[^\s]', text, pos).start` if a match exists, otherwise `len(text)`. This eliminates the per‑character loop and uses the compiled regex engine’s jump capability, which is asymptotically faster for whitespace‑skipping.
