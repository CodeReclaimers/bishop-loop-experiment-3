Replace the while‑loop in _skip_ws with a single call to text.find that scans ahead for the next non‑whitespace character and returns its index, then return that index; this eliminates the per‑character loop and uses the fast C implementation of find. Since _skip_ws is only used to locate the start of the next token, returning the index of the first non‑whitespace character directly is sufficient. This change keeps correctness unchanged while dramatically speeding up whitespace skipping.
