Replace the current loop inside _skip_ws with a single call to text.find(_WS_RE, pos) to jump directly to the next non‑whitespace character instead of checking each character individually. This leverages the pre‑compiled regex _WS_RE to skip all whitespace in one operation, which is O(1) in the number of whitespace characters skipped and avoids the per‑character in _frozenset lookup. The rest of the parser continues to work because it still receives the same resulting position.
