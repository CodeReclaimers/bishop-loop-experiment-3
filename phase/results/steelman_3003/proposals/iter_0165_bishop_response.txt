Replace the manual character‑by‑character loop in `_skip_ws` with a direct call to the compiled `_WS_RE` pattern: instead of advancing `pos` one by one, set `pos = _WS_RE.search(text, pos).end()`. This uses the same regex that already skips whitespace and obtains the new position in a single, O(1)‑sized operation, so the parser skips spaces or tabs much faster while still producing the correct index.
