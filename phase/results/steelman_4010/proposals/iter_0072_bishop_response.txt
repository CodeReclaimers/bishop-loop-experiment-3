We can use this regex to match digits, decimal points, and exponents only, which reduces the number of checks needed during parsing. This optimization helps in reducing the time complexity of the number parsing step.

3. **Use Dynamic Programming for String Concatenation**: Instead of concatenating strings one by one using `out = out + [v]`, we can use a dynamic programming approach to concatenate strings more efficiently. We can maintain a list of strings and their lengths, and only update the last string's length when we need to add new items. This reduces the time complexity of appending to the list.

4. **Optimize Recursive Descent for Object Parsing**: We can optimize the recursive descent algorithm for object parsing by reducing the number of checks needed at each level. For example, instead of checking if the current character is `:` before proceeding with parsing the key-value pair, we can directly check the next character without further validation. This reduces the time complexity of the object parsing step.
