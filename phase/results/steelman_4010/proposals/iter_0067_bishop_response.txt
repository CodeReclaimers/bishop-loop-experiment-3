To optimize the `json_parser.py` for performance, we can leverage Python's built-in string methods and list comprehensions instead of manual character scanning and string concatenation. This approach can significantly reduce the execution time while maintaining correctness.

Specifically, we can replace the explicit loop for parsing numbers with the `int()` function when encountering a digit character and the `float()` function when encountering a decimal point or exponent. For handling strings, we can use slicing to extract substrings directly instead of concatenating characters manually. This reduces both the time complexity and the space required for processing each token.

By leveraging these optimizations, we can expect a noticeable speedup in parsing large JSON documents without compromising the accuracy of the output.
