To speed up parsing significantly, we can precompute a dictionary that maps single-character escape sequences to their corresponding Unicode characters. This eliminates the need for string concatenation and improves performance by reducing the overhead of character manipulation.

For example, instead of building strings like `"\\n"` as needed in the `_parse_string` function, we can use the mapping directly:

```python
_HEX_ESCAPE_MAP = {
    chr(i): i for i in range(128)  # Basic ASCII
}
for i in range(0x10000):
    _HEX_ESCAPE_MAP[format(i, '04x')] = chr(i)
```

This map allows us to quickly look up the corresponding Unicode character for any escape sequence encountered during parsing.
