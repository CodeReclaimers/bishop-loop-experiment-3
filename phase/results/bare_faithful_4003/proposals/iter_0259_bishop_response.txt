One potential optimization idea is to switch from a simple `while` loop with an index-based increment to using a stack-based approach for whitespace skipping in the `_skip_ws` function. This can be done by pushing positions onto a stack whenever a whitespace character is encountered and popping them off when a non-whitespace character is encountered or when a closing brace `{` is found. This reduces the need for string concatenation and allows for faster traversal of the input text.
