Suggest using a generator expression for whitespace skipping in `_skip_ws` function to improve performance. This should reduce time complexity from linear to constant time, as each character is processed once and only once.

```python
def _skip_ws(text: str, pos: int) -> int:
    # Use generator expression to skip whitespace
    return next((i for i, c in enumerate(text[pos:]) if c not in _WS_CHARS), len(text))
```

This change leverages the built-in `enumerate` function to iterate over characters in the string from the specified position without using a loop. The generator expression efficiently checks each character against the whitespace set and stops as soon as it encounters non-whitespace, which is then returned by the function. This reduces the time complexity of iterating through the entire string by avoiding unnecessary comparisons and iterations.
