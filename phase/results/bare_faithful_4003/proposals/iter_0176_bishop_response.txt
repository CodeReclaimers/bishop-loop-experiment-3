One specific change to consider for optimization is to use a stack-based approach for whitespace handling instead of using a generator expression. This would allow us to process whitespace more efficiently and reduce the overhead of list concatenation in the `parse_value` function. By using a stack, we can keep track of the positions of the current character and the start of the next token, allowing us to skip whitespace as we encounter it without creating unnecessary strings or appending to them. This would result in a significant improvement in performance, especially for large JSON documents.
