1. `_skip_ws` uses a Python loop with membership testing instead of regex
2. String concatenation in `_parse_string` uses repeated `+` operations
3. Number parsing uses character-by-character scanning with repeated checks
4. The parser has redundant whitespace handling at every level

Let me analyze the most promising optimization approaches:

1. **Use regex for whitespace skipping** - This could dramatically speed up `_skip_ws`
2. **Use list building + join instead of string concatenation** - For `_parse_string` 
3. **Optimize number parsing with regex or direct conversion** - Instead of character-by-character scanning

The most promising approach is to use regex for whitespace skipping since it's called very frequently and is currently the biggest bottleneck.
