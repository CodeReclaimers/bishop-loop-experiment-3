To improve the performance of the JSON parser, we can optimize the handling of whitespace characters by using a sliding window approach instead of iterating through each character individually. This reduces the time complexity from O(n) to O(1), where n is the length of the input string.

Instead of checking each character for whitespace in every iteration of `_skip_ws`, we will maintain a sliding window that includes the last set of non-whitespace characters and advance it whenever a whitespace character is encountered. This approach allows us to skip over the whitespace efficiently without scanning through the entire string repeatedly.
