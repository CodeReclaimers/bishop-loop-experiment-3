To speed up the JSON parser, you could consider using a streaming parsing approach instead of loading the entire input into memory at once. This would allow you to parse the input character-by-character and only build the data structure as needed, reducing memory usage. This can be achieved by modifying the `_parse_value` function to iterate over the input string one character at a time, checking for different types of JSON values such as numbers, strings, objects, arrays, booleans, and nulls.
