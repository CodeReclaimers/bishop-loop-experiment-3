To speed up the JSON parser, we can use a more efficient way to skip whitespace characters. Instead of processing the entire chunk in one go, we can process it character by character and stop processing once we encounter a non-whitespace character. This reduces the overhead of looping through the string and improves performance significantly.

```python
def _skip_ws(text: str, pos: int) -> int:
    while pos < len(text) and text[pos] in _WS_CHARS:
        pos += 1
    return pos
```

This change uses a `while` loop to iterate over each character in the string until it encounters a non-whitespace character. This approach avoids the overhead of creating temporary slices or using list comprehensions, resulting in faster execution times.
