One specific change to try in `json_parser.py` is to pre-process the input text by removing all whitespace, which will speed up the overall parsing process. This can be achieved using the built-in Python regular expression module (`re`). The mechanism for this change is to define a function `_skip_ws` that scans the input text from a given position and returns the first index of a non-whitespace character, or the length of the string if all characters are whitespace.
