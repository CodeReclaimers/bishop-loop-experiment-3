An efficient way to optimize this parser could be to preallocate lists for array elements and objects, reducing the overhead of string concatenation. This would require modifying `_parse_array` and `_parse_object` functions. By doing so, we can avoid repeatedly building new strings, which is the current bottleneck in parsing large JSON documents.

To achieve this, we can introduce a `buffer` variable that keeps track of the characters read from the input string. Whenever a value (like an object or array element) is parsed, it is appended to the `buffer`. After parsing a complete value, we move the start position of the buffer forward by the number of characters added to it. This way, when new values are parsed, they can be appended directly to the `buffer` without needing to convert it back to a string.

This change not only improves the performance but also reduces memory usage, which is crucial for large JSON documents.
