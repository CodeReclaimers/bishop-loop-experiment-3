One specific change to try in `json_parser.py` to make it faster while keeping it correct is to use a more efficient method for scanning numbers character-by-character. The current approach uses `isdigit()` which has a time complexity of O(k), where k is the number of digits, which can be slow for large numbers. An alternative could be using a dedicated function like `_parse_number_fast`, which scans the number directly and keeps track of its length, allowing it to skip unnecessary checks after finding the end of the number.
