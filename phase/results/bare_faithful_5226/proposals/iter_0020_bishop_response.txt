To make the JSON parser faster, we can optimize the string concatenation in `_parse_string` to reduce the number of allocations and improve performance. Specifically, instead of appending each character individually using `out = out + c`, we can use the `join()` method on a list to collect all characters together before joining them into a string. This reduces the overhead of repeatedly creating new strings, which is a common source of performance issues in Python.

This approach reduces the time complexity from O(n) per character appended to O(k * n), where k is the number of characters in the string being parsed. The `join()` method has an average time complexity of O(k * n) and is generally more efficient than appending each character individually, especially for large strings.
