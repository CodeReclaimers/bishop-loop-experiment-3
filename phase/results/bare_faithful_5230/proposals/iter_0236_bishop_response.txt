To improve performance, we can use a more efficient way to skip whitespace by utilizing the `str.lstrip()` method instead of repeatedly checking each character for whitespace. This will avoid unnecessary loops and reduce the overhead of string operations. The modified code would look like this:

```python
def _skip_ws(text: str, pos: int) -> int:
    return pos + len(text[pos:].lstrip(' \t\n\r'))
```

This change makes it faster by directly trimming the whitespace from the start of the string without iterating over each character.
