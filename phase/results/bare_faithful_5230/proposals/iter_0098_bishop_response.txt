To optimize the `json_parser.py`, we can use a more efficient approach to skip whitespace characters. Instead of using a regular expression, which is generally slower than simple character checks, we can use Python's string methods like `lstrip` or `strip` with appropriate arguments.

Here’s how we can implement this change:

```python
# Replace the existing _skip_ws function with a more efficient one:
def _skip_ws(text: str, pos: int) -> int:
    # Use lstrip to remove leading whitespace characters
    stripped = text[pos:].lstrip()
    return pos + len(stripped)
```

This change makes it faster because `lstrip` is designed to strip whitespace characters from the left side of a string efficiently. The previous code, which used regexes, could be slower if there are many leading whitespace characters, especially in longer strings.
