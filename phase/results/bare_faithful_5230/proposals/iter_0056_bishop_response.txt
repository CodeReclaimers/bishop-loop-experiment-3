One specific change to try in `json_parser.py` is to replace the use of `re.match` with a loop-based approach that skips whitespace characters one by one, as shown below:

```python
def _skip_ws(text: str) -> int:
    pos = 0
    while pos < len(text):
        if text[pos] not in _WS_CHARS:
            break
        pos += 1
    return pos
```

This change avoids the overhead of a regular expression and replaces it with a more straightforward loop that iterates over the string and skips whitespace characters. This should make the parser faster while keeping it correct, as it does not need to match regular expressions to skip whitespace.
