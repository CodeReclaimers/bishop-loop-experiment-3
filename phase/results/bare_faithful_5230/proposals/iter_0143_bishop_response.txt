To improve performance, we can implement a more efficient way to skip whitespace in our JSON parser. One approach is to use a generator expression inside `_skip_ws` that yields characters one by one until it encounters non-whitespace. This allows us to stop processing as soon as we find the first non-whitespace character and then continue parsing from there, avoiding unnecessary iterations over whitespace characters.

Here's how the change would look:

```python
def _skip_ws(text: str, pos: int) -> int:
    while pos < len(text) and ord(text[pos]) <= 32:
        pos += 1
    return pos
```

This change improves performance by reducing the number of iterations required to skip whitespace, especially for longer strings.
