Replace the calls to the compiled regex _WS_PATTERN.search inside the whitespace‑skipping loops with a direct call to the fast _skip_ws function that uses the pre‑computed _WS_CHARS frozenset; this eliminates the overhead of regex compilation and matching. Specifically, change the lines in _parse_object and _parse_value that set pos via m.end() to simply pos = _skip_ws(text, pos) so the parser continues to skip whitespace using the O(1) set‑membership loop instead of the regex engine.
