Replace the regex‑based whitespace‑skipping calls that use _WS_PATTERN.pattern.search with direct membership checks using _WS_CHARS instead of iterating over the compiled pattern. This eliminates the overhead of invoking a regex engine for trivial character‑by‑character skipping. The same while loop that builds pos by incrementing when text[pos] is in _WS_CHARS already handles whitespace efficiently, so the change replaces the redundant regex search with a simple O(1) character test.
