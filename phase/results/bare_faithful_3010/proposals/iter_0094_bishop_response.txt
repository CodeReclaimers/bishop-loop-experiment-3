Replace the repeated calls to `_WS_PATTERN.pattern.search(text, pos).end()` in `_parse_object` and `_parse_array` with a simple while‑loop that advances `pos` while `text[pos] in _WS_CHARS`. This avoids the overhead of regex compilation and pattern matching for each whitespace segment, using only the pre‑computed `_WS_CHARS` set for O(1) checks. The result is faster whitespace skipping while preserving correctness.
