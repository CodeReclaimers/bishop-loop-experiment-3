Replace the repeated use of _WS_PATTERN.match to skip whitespace with a single str.find call that returns the next position after a run of whitespace characters, which avoids the overhead of compiling and re‑matching the regex each time. In parse and _parse_object use pos = text.find(next(c for c in _WS_CHARS), pos) or a simple loop that increments pos while text[pos] is in _WS_CHARS to fast‑forward through whitespace instead of generating a match object each iteration. This single replacement reduces the per‑iteration cost and keeps correctness intact.
