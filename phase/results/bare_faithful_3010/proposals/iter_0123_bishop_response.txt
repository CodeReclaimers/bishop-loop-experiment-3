Replace the repeated use of _WS_PATTERN.pattern.span(pos)[1] which repeatedly calls the compiled regex against the same input with a simple loop that advances pos while text[pos] is in _WS_CHARS. This eliminates the overhead of regex matching and directly uses the pre‑computed frozenset _WS_CHARS for O(1) membership tests. The change keeps the same whitespace‑skipping semantics while making each iteration faster.
