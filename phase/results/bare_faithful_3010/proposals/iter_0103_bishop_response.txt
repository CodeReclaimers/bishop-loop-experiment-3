Replace any call to `_WS_PATTERN.search(...).end()` for skipping whitespace with a direct check against the pre‑computed `_WS_CHARS` frozenset, advancing `pos` incrementally while looping. This avoids the overhead of regex compilation and repeated pattern matching, so whitespace skipping becomes an O(1) loop instead of invoking a compiled regex each time. The change keeps correctness because the same character set is still used for skipping.
