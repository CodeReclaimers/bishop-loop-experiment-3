Replace the calls to `_WS_PATTERN.pattern.search` in `parse` and `_parse_object` with a direct loop that iterates while `text[pos] in _WS_CHARS`, as already used in `_skip_ws`; this eliminates the regex compilation and per‑call search overhead, letting the fast frozenset membership test handle whitespace skipping. The change keeps correctness because the same set of whitespace characters is still ignored, just without the overhead of pattern matching.
