Replace the repeated calls to `_WS_PATTERN.pattern.search(...) .end()` with a simple loop that advances `pos` while `text[pos]` is in `_WS_CHARS`, using the pre‑computed `_WS_CHARS` set instead of compiling a regex each time; this eliminates the overhead of regex matching and makes whitespace skipping O(1) per character. Consequently, both `parse` and `_parse_object` will skip whitespace faster while preserving the same logical behavior.
