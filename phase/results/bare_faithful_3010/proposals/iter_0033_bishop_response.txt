The parser repeatedly scans the input string for whitespace using a while loop in _parse_value and _skip_ws, which forces Python to check each character individually, so replace these loops with a single call to re.sub using the compiled _WS_PATTERN to strip all whitespace at once, keeping the position pointer at the first non‑whitespace character and thus eliminating repeated character‑by‑character checks. This single‑pass whitespace removal reduces the number of character checks dramatically while preserving correctness.
