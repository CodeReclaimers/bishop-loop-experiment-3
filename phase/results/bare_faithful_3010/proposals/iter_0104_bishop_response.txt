Pre‑compute a single list of contiguous whitespace spans using `re.finditer(r'[ \t\n\r]+')` once at load time and replace the repeated `_skip_ws` calls that run the regex each time with a binary search into that list to jump to the next non‑whitespace position. This eliminates the overhead of repeatedly compiling and executing the regex pattern, turning O(k) character‑by‑character skips into O(log m) look‑ups where m is the number of span boundaries.
