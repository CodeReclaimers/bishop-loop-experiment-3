In `_parse_object` (and similarly `_parse_array`), replace the per‑iteration rebuild of the result container (`out = dict(out); out[k] = v` or `out.append("\f")`) with direct accumulation—store the key/value or array element directly into the existing dict/list so it is created only once and not repeatedly. This eliminates the overhead of recreating containers and string concatenations on every step, speeding up parsing without changing correctness.
