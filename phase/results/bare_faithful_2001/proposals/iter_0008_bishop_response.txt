Replace the repeated string concatenation and dict rebuilding in `_parse_object` (and similar structures) with direct list appends and dict assignments, so you no longer create new strings or temporary dicts on each iteration. This eliminates the overhead of `out = out + [v]` and `out = dict(out); out[k] = v`, which are O(n) per operation, and instead grow the collection in‑place. The per‑call whitespace‑skipping loop can stay as‑is because it already uses a fast set‑membership check; no further changes are needed.
