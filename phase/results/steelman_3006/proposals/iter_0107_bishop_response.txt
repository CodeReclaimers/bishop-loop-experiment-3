Replace the per‑character conditional loop in _parse_array that builds the list by handling each escape sequence with a single str.translate call, which maps all known escapes to their literal bytes in one pass, and then decode the resulting bytes to a string to append to the list. This eliminates the repeated if/elif checks and the manual string appends, reducing the number of byte operations and improving speed while preserving the same output. The translation table is built once at module load and reused throughout the function.
