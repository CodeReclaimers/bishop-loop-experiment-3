In `_parse_number` replace the `while pos < n and text[pos] in _DIGIT_CHARS: pos += 1` loop with a single call to `text.find` that locates the next character outside the digit set, e.g. `pos = text.find(next(c for c in text[start:] if c not in _DIGIT_CHARS), start)`. This skips the entire digit run in O(1) instead of O(k) per digit.
