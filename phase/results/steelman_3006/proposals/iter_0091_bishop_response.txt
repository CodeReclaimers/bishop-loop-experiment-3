Replace the set‑based membership checks (e.g., `c in _WS_CHARS`, `c in _DIGIT_CHARS`, `c in _HEX_CHARS`, `c in ("e","E")`) with a single‑byte boolean lookup table keyed by `ord(c)` so each comparison runs in constant time without hashing. This eliminates the overhead of set iteration and dramatically speeds up the parser while preserving correctness.
