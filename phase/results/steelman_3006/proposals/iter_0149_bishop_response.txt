Replace the _skip_ws function with a single call to text.find(''.join(_WS_CHARS), pos) that directly returns the next non‑whitespace position without iterating character‑by‑character. This eliminates the while‑loop overhead while still returning the correct index because find returns either the index of the first matching whitespace or len(text) if none remain, and the surrounding code can then use that result directly. This change reduces the per‑skip cost from O(k) character checks to a single O(1) substring search.
