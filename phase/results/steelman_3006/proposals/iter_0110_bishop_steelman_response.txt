CRITIQUE: The suggestion to replace the while loop with `text.find()` is fundamentally flawed because `text.find()` searches for a substring, not individual characters, so `text.find(' \t\n\r', pos)` would find the first occurrence of any whitespace character but wouldn't skip all consecutive whitespace. The proposed approach would fail to skip multiple consecutive whitespace characters correctly.

STEELMAN: The steelman approach is to optimize `_skip_ws` by using `str.translate` with a translation table that maps all whitespace characters to a single sentinel character, then using `str.find` to locate the first non-sentinel character. This avoids the character-by-character loop while maintaining correctness.

def _skip_ws(text: str, pos: int) -> int:
    # Use str.translate with sentinel to skip whitespace efficiently
    if pos >= len(text):
        return pos
    # Create translation table mapping all whitespace to a sentinel
    trans_table = str.maketrans(_WS_CHARS, '\x00' * len(_WS_CHARS))
