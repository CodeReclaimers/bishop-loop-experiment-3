Replace the character‑by‑character `_skip_ws` loop with a single call to `text.find` that returns the index of the first non‑whitespace character, then iterate only over any remaining whitespace. This eliminates the O(n) iteration over each whitespace character and reduces the function to O(k) where k is the number of whitespace runs. The result is a single, fast locate operation that skips all leading whitespace at once.
