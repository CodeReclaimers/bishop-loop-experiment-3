Replace the character‑by‑character whitespace‑skipping loops in both _skip_ws and the _skip_ws call within _parse_value with calls to str.translate using a pre‑built translation table that maps every whitespace character to a unique sentinel, then locate the first non‑sentinel character to obtain the new position in one pass. This eliminates the O(k) while loop overhead per whitespace character, turning each skip into an O(1) operation.
