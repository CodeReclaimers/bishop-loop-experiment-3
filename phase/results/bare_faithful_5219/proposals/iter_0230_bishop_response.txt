To make the JSON parser faster while maintaining correctness, we can eliminate unnecessary whitespace skipping by using a set to store the whitespace characters instead of looping through them with `str.lstrip`. This change is implemented in the `_skip_ws` function as follows:

```python
# Instead of iterating over ' \t\n\r', use a set for faster lookup
_WS_CHARS = frozenset(" \t\n\r")
```

This optimization reduces the time complexity from linear to constant on average, making the parsing process more efficient.
