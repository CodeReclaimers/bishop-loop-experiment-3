To speed up the JSON parser, we can use a more efficient method to determine whether a character is whitespace. Currently, we are using a regex to check for whitespace characters, which has a time complexity of O(n), where n is the length of the input string. This approach can be improved by using a set containing all whitespace characters and then checking each character against this set.

Specifically, we can modify the `_skip_ws` function to use a set of whitespace characters instead of a regular expression. Here's how the modified function might look:

```python
def _skip_ws(text: str, pos: int) -> int:
    n = len(text)
    ws_chars = frozenset(" \t\n\r")
    while pos < n and text[pos] in ws_chars:
        pos += 1
    return pos
```

By using a set of whitespace characters, we eliminate the need for regular expressions and can achieve the same result with O(1) time complexity. This change should significantly improve the performance of the JSON parser while maintaining correctness.
