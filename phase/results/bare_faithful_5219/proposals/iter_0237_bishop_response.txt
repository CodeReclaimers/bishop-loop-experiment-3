One specific change to try is using a more efficient string concatenation mechanism. Currently, the code uses `out = out + [v]` and `out = dict(out); out[k] = v`, which results in multiple allocations and copies for each element added to the output structure. By replacing these with direct assignment (`out.append(v)`) and using a dictionary comprehension (`out = {k: v for k, v in out.items()}`), we can avoid unnecessary copying and improve performance.
