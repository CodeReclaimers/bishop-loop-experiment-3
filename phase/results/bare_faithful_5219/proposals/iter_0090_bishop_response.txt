To improve the performance of the JSON parser while keeping it correct, we can optimize the string concatenation in the `parse` function. Instead of appending strings to a list and then converting the list to a dictionary at the end, we can use the `OrderedDict` class which maintains the order of insertion. This approach eliminates the need for rebuilding the dictionary on each step.

    value, pos = _parse_value(text, pos)
    pos = _skip_ws(text, pos)
    if pos != len(text):
        raise JSONParseError(f"trailing content at position {pos}")
