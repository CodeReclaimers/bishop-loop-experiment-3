To improve the performance of the JSON parser in `json_parser.py`, we can leverage a more efficient way to parse numbers by directly scanning for number characters instead of building and concatenating strings. This will avoid the overhead of string manipulation, especially for large numbers, which are common in JSON data.

We can then modify `_parse_value` to use this new function instead of building strings.
