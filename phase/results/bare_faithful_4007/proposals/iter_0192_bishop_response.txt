To improve the performance of the JSON parser, one potential optimization is to use a more efficient method for scanning numbers in the input string. Instead of using `ord()`, which has a time complexity of O(1) per character, you can precompute the ASCII values of the digits and special characters used in numbers and store them in a dictionary or set. This way, when scanning the input, you can directly compare the current character with the stored values instead of calling `ord()` each time.

Specifically, you could modify the `_parse_number` function to use a set of known digit and special character ASCII values and return early if a non-digit character is encountered before all digits are scanned. This would reduce the overhead of the `ord()` calls and improve the performance of the parser.
