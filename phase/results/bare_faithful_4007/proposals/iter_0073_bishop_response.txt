One improvement is to switch from using `str` for string concatenation to f-strings or `join`. This will be faster because f-strings are compiled into a single executable string, while concatenation needs to create intermediate strings at each stage.

```python
out = "".join([v])  # Replace with out = str(v) or out += str(v)
```

This change reduces the overhead of creating temporary strings in the loop and makes the code more efficient.
