To optimize the JSON parser for speed while keeping it correct, we can use a more efficient method to parse numbers without relying on regular expressions for each digit. One approach is to iterate through the string character by character and use a loop to determine if a number starts with a '-' or digit. This eliminates the need for regular expressions and improves performance.

The idea is to track the current state of the parser (whether it's processing a number, an object, or array), and based on this state, parse numbers directly within the loop without waiting for the end of a token. This way, we can process numbers as they appear in the input string without having to wait for entire words or phrases to complete.

By implementing this change, we expect the parser to consume JSON inputs more quickly while maintaining its correctness.
