**Suggestion:** Use a `deque` instead of a list to build the parsed object and array structures. This change improves the performance by reducing the overhead of string concatenation, which is a common bottleneck in parsers.

The `deque` in Python is implemented as a doubly-linked list with constant-time appends and pops from both ends, making it faster than a regular list for appending elements and reassigning values. By using a deque, we can avoid rebuilding the object structure on each step of the recursive descent parsing process, which reduces the time complexity of the function significantly.
