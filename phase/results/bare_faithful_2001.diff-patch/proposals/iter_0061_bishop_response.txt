Replace the regular‑expression call inside `_skip_ws` with a simple manual loop that increments `pos` while `text[pos].isspace()` is true, instead of letting the regex engine find and match the whitespace. This eliminates the cost of re‑compiling and matching on each call, letting the loop skip whitespace in O(k) time where k is the number of skipped characters, which is the same asymptotic cost but with far lower constant factors. Apply this change only to `_skip_ws`; all other uses keep the same result.
