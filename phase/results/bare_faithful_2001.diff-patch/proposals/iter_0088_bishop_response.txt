Replace the `_skip_ws` function with a direct pointer‑advance loop that skips whitespace characters one by one instead of using the compiled regex `_WS_RE.match`. This eliminates the regex‑matching overhead and reduces the function’s runtime from O(1) to O(k) where k is the number of characters skipped, while still advancing `pos` to the next non‑whitespace byte. The rest of the parser can keep using the same positional logic, maintaining correctness.
