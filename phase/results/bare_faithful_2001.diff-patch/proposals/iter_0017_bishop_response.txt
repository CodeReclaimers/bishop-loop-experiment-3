Replace the `_skip_ws` function with a simple loop that manually advances the index while the current character is one of the whitespace characters (' ', '\t', '\n', '\r', '\f', '\v'), skipping ahead until a non‑whitespace character is found. This eliminates the overhead of compiling and executing a regular‑expression match for each whitespace skip, which is the dominant cost in the parser. The loop is O(1) per whitespace character and maintains the same correctness.
