Replace the current `_skip_ws` function with a simple while‑loop that increments `pos` while the character at `pos` is a whitespace character, instead of using the regex `_WS_RE.match`. This eliminates the overhead of a compiled regex and the temporary match object, which is the dominant cost in every parse step. The loop is O(k) per whitespace run just like the regex version, but it avoids the pattern‑matching machinery.
