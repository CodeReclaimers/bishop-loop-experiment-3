A possible optimization idea for `json_parser.py` is to use a more efficient regex pattern for whitespace skipping. Currently, `_skip_ws` uses a loop to iterate over the string and skips whitespace characters. This approach works well but can be slow, especially for large inputs.

To speed up this part of the code, we can replace the loop with a more optimized regular expression. For example, using Python's `re.findall()` function instead of iterating manually can significantly improve performance. This change directly affects the `_skip_ws` function and does not require any other changes to the rest of the code. The use of a regular expression improves efficiency by leveraging the compiled regex engine, which can execute faster than simple loops for repeated tasks like this.
