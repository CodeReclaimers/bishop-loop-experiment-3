The suggestion seems to conflate the issue of inefficient list/dict building with string building, which are separate performance bottlenecks. Additionally, generators don't reduce memory usage or improve performance in this context since the parser still needs to accumulate all parsed elements into a final collection.

The steelman approach would replace these with direct mutation of lists and dicts to avoid repeated allocations, which aligns with the stated goal of reducing unnecessary allocations and improving performance.
