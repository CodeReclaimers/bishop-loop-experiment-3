To improve performance, we can use a generator to yield values as they are parsed instead of building an entire list in memory. This will reduce the amount of time spent creating and managing lists, which can be particularly beneficial for large JSON documents. We can achieve this by modifying the `_parse_value` function to return a tuple containing the parsed value and the new position after parsing that value. The caller can then use these values to update the parse position and continue parsing from the next character.
