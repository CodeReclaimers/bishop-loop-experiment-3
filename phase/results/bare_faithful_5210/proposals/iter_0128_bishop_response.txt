One specific change to try in `json_parser.py` is to use a generator function for parsing JSON values instead of returning an entire value at once. This allows us to parse each value one by one, which can be more efficient and reduce memory usage. We could implement this by modifying the `_parse_value` function to return a tuple containing the parsed value and the next position in the text. The caller would then accumulate these values into a list or dictionary as needed.
