Replace the explicit while‑loop that advances `pos` over whitespace in multiple places (e.g., at the start of `parse`, in `_parse_value`, and around commas/braces) with calls to `_skip_ws`, which uses a single C‑level `find` to locate the next non‑whitespace character. This eliminates the per‑character Python iteration, letting the C implementation handle the loop, which is typically much faster.
