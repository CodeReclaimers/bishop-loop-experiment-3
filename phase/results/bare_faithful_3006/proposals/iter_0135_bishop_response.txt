Replace every call to `_skip_ws` with an inline while‑loop that directly skips whitespace, e.g. `while pos < len(text) and text[pos] in _WS_CHARS: pos += 1`. This removes the function‑call overhead and lets the fast C‑level set membership test run in a tight loop, which is the main source of slowdown. The result is a faster parser that still correctly advances the cursor through whitespace.
