Replace the repeated manual whitespace‑skipping loops that increment `pos` one character at a time with a single call to a compiled regular‑expression that finds the next non‑whitespace position in one go. Using a pre‑compiled pattern `re.compile(r'[ \t\n\r]+')` and `pos = ws.search(text, pos).start()` eliminates the Python‑level while loops, so whitespace is consumed in constant time instead of linearly scanning each character. This keeps correctness because the pattern matches exactly the same characters defined in `_WS_CHARS`.
