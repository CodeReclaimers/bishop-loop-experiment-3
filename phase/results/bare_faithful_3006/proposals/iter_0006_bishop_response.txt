Change the digit and hex‑character checks in `_parse_number`, `_is_hex4`, and any other place that uses `_DIGIT_CHARS` or `_HEX_CHARS` to use direct range comparisons (`'0' <= c <= '9'` and `c.lower() in '0123456789abcdef'`) instead of set membership tests. This eliminates O(1) hash lookups and replaces them with simple O(1) arithmetic checks, which Python executes faster, while preserving correctness.
