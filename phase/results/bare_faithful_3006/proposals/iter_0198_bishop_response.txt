Replace the repeated while‑loops that increment pos one character at a time to advance past whitespace with the existing _skip_ws function, which uses text.find to locate the next non‑whitespace character in a single call. Apply this change in parse (right after the initial skip) and in _parse_value when handling keys, strings, numbers, and booleans, so the parser jumps over whitespace in O(1) time instead of O(k) where k is the length of the whitespace run. This reduces the number of Python iterations, yielding a noticeable speed gain while preserving the same logical flow and error handling.
