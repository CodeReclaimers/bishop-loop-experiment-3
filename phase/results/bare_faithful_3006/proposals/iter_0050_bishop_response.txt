Replace the `_skip_ws` helper with a single call to `text.find(WS_PAT, pos)` where `WS_PAT` is a pre‑computed constant string `''.join(_WS_CHARS)` defined at module level. This avoids recomputing the whitespace pattern on every call and reduces the per‑call overhead from a Python loop to a fast C‑level search, while still correctly advancing the position past any leading whitespace.
