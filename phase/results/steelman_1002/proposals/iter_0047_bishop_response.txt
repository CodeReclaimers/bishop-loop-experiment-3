To speed up the JSON parser, we can use a different approach for parsing numbers by converting them to floating-point numbers directly at the point they are encountered in the input string. This avoids the overhead of parsing and validating each number individually, as it would require more time and resources. We can do this by maintaining an array of already parsed numbers that we can reuse when encountering another number in the input. This way, once a number is parsed, it remains available for subsequent uses without needing to be re-parsed.
