To make the JSON parser faster, we can use a generator function to yield values as they are parsed, rather than creating them all at once. This approach reduces memory usage and improves parsing speed by avoiding unnecessary allocation and copying of data. We can modify the `_parse_value` function to return a tuple containing the value and the position of the next character after parsing it. The caller can then use this information to decide whether to continue parsing or stop early if they know that no further values are expected.
