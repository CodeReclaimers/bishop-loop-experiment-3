In `json_parser.py`, we can optimize the recursive descent parser for object keys by using a dictionary to store keys instead of appending to a list. This approach avoids unnecessary string concatenations and rebuilds-on-each-step collections, which are costly operations in Python. We will replace the current `out = out + [v]` line with `out[k] = v` where `k` is the key and `v` is the value being parsed. This change significantly improves the parsing speed by reducing the overhead of creating new lists.
