To improve the performance of the JSON parser, we can leverage Python's built-in `int()` function to parse integers directly instead of manually parsing them character-by-character. This avoids the overhead of string concatenation and improves efficiency by reducing the number of allocations.

Here is the suggested change:
In `_parse_number` function, replace the line:
```python
s = text[start:pos]
```
with:
```python
s = int(text[start:pos])
```
This change ensures that integers are parsed directly into the `int()` function, bypassing the need for string manipulation and reducing the overhead associated with concatenation.
