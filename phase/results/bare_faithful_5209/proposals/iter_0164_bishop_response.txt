One potential optimization idea is to use a generator function instead of `parse` returning a single value at once. This would allow the parser to yield values as they are encountered, reducing memory usage and improving throughput on large inputs.

```python
def parse_generator(text: str) -> Iterator[Any]:
    if not isinstance(text, str):
        raise JSONParseError("input must be a string")
    pos = _skip_ws(text, 0)
    while pos < len(text):
        value, pos = _parse_value(text, pos)
        yield value
```

This approach would allow the caller to handle the parsing in chunks as they are ready, potentially reducing the total parsing time.
