To speed up the JSON parser, we can use a more efficient way to skip whitespace in the `_skip_ws` function. Instead of looping through each character individually, we can directly remove leading whitespace from the string using slicing. This reduces the number of comparisons and skips unnecessary characters.

```python
def _skip_ws(text: str, pos: int) -> int:
    return pos + len(text[pos:].lstrip(' \t\n\r'))
```

This change significantly improves the performance by reducing the number of iterations required to skip whitespace, especially for longer strings.
