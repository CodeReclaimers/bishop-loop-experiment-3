A suggestion is to use a stack-based parser instead of recursion, as it allows for more efficient handling of nested structures without the overhead of recursive calls. This change involves using a stack to keep track of the current state and pushing new items onto the stack when encountering opening brackets `{` or `[`, and popping them off when encountering closing brackets `}` or `]`. This way, we can avoid calling the `_parse_value` function multiple times for nested structures, which reduces the time complexity.
