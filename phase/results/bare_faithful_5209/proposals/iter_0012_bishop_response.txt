To improve the speed of this JSON parser, we can make the following change:

1. **Use a Regular Expression for Whitespace**: We can use a regular expression to skip whitespace instead of checking each character individually.

```python
import re

```

2. **Reformat the _skip_ws Function**: Instead of using a loop, we can use `re.match` to find the next non-whitespace character in one go.

```python
def _skip_ws(text: str, pos: int) -> int:
    return re.match(r"\s+", text[pos:]).end()
```

This change leverages the efficiency of regular expressions for matching patterns in strings and reduces the time complexity of skipping whitespace.
