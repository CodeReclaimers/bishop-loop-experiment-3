To optimize the `json_parser.py` for speed, we can reduce the overhead associated with string concatenation by using a list to build the output data structure directly instead of repeatedly calling `out = out + "\n"` and `out = out + " "`.

This change involves creating an empty list `out_list` before starting the parsing process. As we encounter each JSON element, we append it to this list instead of directly modifying `out`. Once all elements have been parsed, we convert `out_list` to a dictionary or list as needed and return it. This approach avoids the overhead of string concatenation and provides a more efficient way to build the final output structure.

This change reduces the time complexity of parsing JSON from O(n^2) (where n is the number of characters in the input) to linear time, making the parser faster while maintaining its correctness.
