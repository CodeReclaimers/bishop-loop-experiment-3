CRITIQUE: The suggestion to replace the while-loop in `_skip_ws` with a regex search would not work correctly because `re.search()` finds the *first* match, not the *longest* contiguous sequence of whitespace starting at the given position. This would fail to skip all leading whitespace and leave the parser in an inconsistent state. Additionally, the regex approach would not integrate cleanly with the existing code that needs to advance through the input character-by-character for parsing other structures.

STEELMAN: The steelman version of the suggestion is to use `re.match()` instead of `re.search()` to match the *entire* leading whitespace sequence starting at the given position, and then advance the position by the match length. This preserves the performance benefits of regex while maintaining correct parsing behavior and integrating cleanly with the existing code structure.
