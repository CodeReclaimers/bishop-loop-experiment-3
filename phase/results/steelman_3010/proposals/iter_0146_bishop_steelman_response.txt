CRITIQUE: The suggestion to replace the manual loop in `_skip_ws` with a regex match would fail because `re.match()` only matches at the beginning of the string, not from an arbitrary position. Additionally, the regex would need to be applied repeatedly in a loop since the current implementation advances position by one character at a time, and a single match won't handle multiple whitespace characters in one go.
STEELMAN: The steelman is to use `re.match()` starting from the current position, but repeatedly apply it in a loop until no more whitespace is found, or better yet, use `re.search()` with a pattern that matches one or more whitespace characters starting from the current position, and advance the position by the match length.
