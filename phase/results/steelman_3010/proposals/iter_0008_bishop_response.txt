Replace the O(1) frozenset membership checks for ASCII characters in `_skip_ws`, `_parse_value`, `_parse_string`, `_parse_number`, and the escape‑handling code with a pre‑computed boolean lookup table keyed by `ord(c)`. Instead of `c in _WS_CHARS` or `c in _DIGIT_CHARS`, the parser would consult a simple array (`_is_ws[c] = True/False`) built once from the frozenset, eliminating hash lookups and set membership overhead on each character. This reduces per‑character overhead without changing parsing logic.
