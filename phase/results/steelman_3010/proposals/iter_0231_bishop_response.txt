Remove the `_WS_PATTERN` variable and any code that calls it, since the `_skip_ws` function already skips whitespace in O(1) time using a precomputed set and a simple loop. By relying exclusively on `_skip_ws` throughout `parse`, `_parse_value`, and any other whitespace‑skipping calls, you eliminate the overhead of compiling and executing a regular expression.
