Replace the manual character‑by‑character whitespace skipping in `_skip_ws` with a single call to the pre‑computed skip table generated by `_build_skip_table` using the compiled `_WS_PATTERN`. This table lets the parser jump directly to the next non‑whitespace position in one operation instead of iterating over each character, thus eliminating the O(n) loop and improving speed while preserving correctness.
