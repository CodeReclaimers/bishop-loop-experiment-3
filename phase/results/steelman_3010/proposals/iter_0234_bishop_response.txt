Replace the manual character‑by‑character loop in _skip_ws with a single call to the pre‑compiled _WS_PATTERN to jump directly to the end of the whitespace sequence, e.g. pos = _WS_PATTERN.search(text, pos).end() or pos = _WS_PATTERN.match(text, pos).end() so the parser skips all whitespace in constant time instead of O(n). This keeps correctness because the pattern matches exactly the same whitespace characters and returns the same index.
