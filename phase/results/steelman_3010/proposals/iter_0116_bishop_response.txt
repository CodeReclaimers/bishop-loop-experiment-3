Replace the manual character‑by‑character whitespace loop in `_skip_ws` with a single call to the pre‑compiled regex `_WS_PATTERN.search` to obtain the next non‑whitespace index instead of iterating one character at a time. This leverages the highly optimized compiled regular‑expression engine, turning a O(k) loop into an O(1) pointer jump and eliminating redundant Python bytecode overhead. Since the regex only targets the same set of characters defined in `_WS_CHARS`, correctness is preserved.
